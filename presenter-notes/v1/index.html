設定（初回だけ・以後は自動）

① 連動の鍵（client-id）：Figma OAuthアプリのID。下のアドレスを Embed API の許可オリジンに登録。

登録するオリジン

② Figmaアクセストークン：スライド画像・自動同期・バックアップに使用。Figma › 自分の名前 › Settings › Security › Personal access tokens › Generate new token（File content: Read）。このブラウザ内だけに保存。

③ Notion バックアップ（任意・保険）：「Notionへ反映」ボタンを押した時だけ Notion の1ページへ保存します（自動反映はしません）。ツールが動かない時の保険用。
手順：① Notionで連携（Integration）を作成 → 「内部インテグレーションシークレット」をコピーして下に貼る。② バックアップ先の Notion ページを開き、右上「•••」› 接続 から、作った連携を追加（これをしないと書き込めません）。このブラウザ内だけに保存。
