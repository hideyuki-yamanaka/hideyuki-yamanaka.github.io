### 3. スライダー（つまみ）の範囲と刻み

| 項目 | 決まり | 部品 |
|---|---|---|
| 真ん中 | いまの値がつまみの真ん中に来る。範囲は **AnyFlow 式の自動の取り直し**（2026-09-27 ヒデさん決定）：半幅＝いまの値−床（書いた下限が0なら床0／正の数ならその半分／マイナスを含むなら床なし）。床に張り付いた値（0本・0秒など）は、少し動かすだけで変化が出る幅を上へ取る。旧 `autoCenter` は廃止 | ✅ |
| 範囲の幅 | 下限0の項目は自動で「0〜いまの値の2倍」＝既定値の±100%（例: 既定100 → 0〜200）。**端（1割）で手を離すと、そこを真ん中に範囲を取り直す**ので、どこまでも広げられる（狭くはしない） | ✅ |
| 0＝いまの位置 のもの | 位置のずらし（X/Y/Z）・ギャップのずらしなど、0が「いまのまま」の項目は**マイナス〜プラスで 0 を真ん中**（例: −300〜300px。＋で右／下／手前）（2026-08-28）。部品では `signed:true` を付ける | ✅ `signed:true` |
| 例外 | ①物理的な上限がある項目（不透明度 0〜100% など）は `clamp:true`＝書いた範囲のまま動かさない ②0＝オフの項目（ブラー0など）は床が0なので下端が0になる | ✅ `clamp:true` |
| 刻み | **細かく**（2026-09-27 改定）。目安は AnyFlow V5 の実際の値＝ px は 1〜2px（大きな距離でも 4px 程度）・秒は 0.05秒・倍率は ×0.05・% は 1〜5%（書いた範囲のおよそ 1/50） | ― |
| 範囲の外 | 外から値が変わって範囲を出た時（案の切り替え・`sync()` など）は、つまみの範囲を取り直して追いつく | ✅ |
| 決まりに止まる | **余白・サイズ・角丸・文字サイズの px のつまみは、デザインの数値の決まり（ルール集 4-7）の値に止まる**：4の倍数（10px以下は2刻み・文字は14pxと18pxも可・角丸は完全な丸も可）。動かしても打ち込んでも、13px なら 12px のように一番近い値へ（同じ差なら大きい方）。位置（X/Y/Z・ずらし）・線幅（0.5px・1pxも可）・影・ぼかし・不透明度・秒・%・倍率は止めない。種類は名前から見分ける。見る順番は 角丸→余白→幅・高さ→文字（文字・フォント・本文・見出し・タイトル・ラベル・キャプション・コピー）→大きさ・サイズ（2026-09-28：「本文サイズ」「bodySize」が大きさ扱いになり 14・18 が寄っていたのを直した）。項目に `grid:'spacing'|'size'|'radius'|'fontSize'` を書けばそれに従う。止めたくない項目は `grid:false`、パネル全体なら `TunePanel.create({ grid:false })`）（2026-09-27 ヒデさん） | ✅ |

> 書いた min / max は「床（下限）」と「最初の幅の目安」に使う。AnyFlow の `slider()` の中の `rangeFor()`（2026-08-27）と同じ計算（部品では `TunePanel.utils.rangeFor`）。
> 右の数値を押すと、範囲の外の値も直接打ち込める。2026-09-27 にヒデさんがこの作りに決めた（食い違い一覧 A1 は決着）。

### 4. 切り替え（ピル・2〜3択・タブ）

| 項目 | 決まり（AnyFlow V5） | 部品 |
|---|---|---|
| どれを使うか | 案（デザインの案）を選ぶ＝**案ピル**／2〜3択・する/しない＝**2〜3択ボタン**（セグメント）／表示・非表示をいくつも＝1行に並べたチップ／ページの切り替え＝タブ。**同じ用途には必ず同じ部品**を使い、独自の切り替えUIを作らない（2026-09-20） | ✅ 案ピル（`pills`）・2〜3択（`seg`・`toggle`）・チップ（`chips`）・タブ |
| する/しない 以外の「選ぶ」行 | 全部、案ピル（⋯ 付き）にそろえる（2026-09-18） | ✅ |
| 番号 | 見えている順に 1, 2, 3… と自動で振り直す（消すと詰まる。欠番を作らない）。元の ID はピルに乗せると吹き出しで出る | ✅ |
| 「現行」 | 先頭・番号なし。⋯ から消すこともできる（2026-09-18） | ✅ 選択肢に `fixed:true` |
| ⋯ メニュー | 各ピルの右端。★ ピン留め（解除）／⤓ いまの設定で上書き／↺ 上書きを解除（上書きした案だけ）／🗑 削除 | ✅ |
| ★ ピン留め | 上に「★ ピン留め」の見出しを付けた**別の段**に ★1, ★2… で出し、通常の並びからは外す（2026-09-16） | ✅ |
| 🗑 削除 | 確認してから一覧から隠す（戻せる）。**最後の1案は消せない**（セクションそのものは消さない）。選んでいた案を消したら残りの先頭へ | ✅ |
| 消した案を戻す | 列の最後の「↺ 消した案を戻す (n)」→ 一覧から1件ずつ戻す。n はまだコードから消していない案だけを数える | ✅ |
| 1案だけ残った時 | 選ぶ意味が無いので、その案を既定にして**ピルと名前の行を隠す**（2026-09-18／名前だけ残さない 2026-09-27 AnyFlow の `labelEl`）。**ただし消した案がある時は「↺ 消した案を戻す (n)」だけは残す**（画面から戻せなくなるため・2026-09-27 ヒデさん決定。AnyFlow は欄ごと隠す）。消した案が無い（コードに1案しか無い）時は欄ごと隠れ、中身が空になった見出しも隠れる。案を戻したら全部戻る | ✅ |
| 案だけの項目 | その案だけに効くつまみは、**その案を選んでいる時だけ出す**（2026-09-14〜26 に何度も指定）。パネル全体は作り直さず、その部分だけ見せる／隠す。出し入れする部分は切り替えのすぐ下に置き、それより上の行は動かさない | ✅ `only:'案の値'`（作り直さず、その部分だけ出し入れ。`when` も作り直さない） |

### 7. 値の持ち方（2軸の独立・絶対ルール）

**調整パネルを作り直しても、案を作り直しても、この2軸の独立は必ず残す**（2026-09-19〜20 ヒデさん強く指定）。

**軸1　案（バリエーション）ごと**
- ある案で動かした値（**位置のずらし・余白・文字サイズも含む**）は、ほかの案に出ない。例: キービジュアルの「強調」でいじった位置は「ノーマル」に効かない。
- 作り方は2つ。A）値の入れ物を案ごとに分ける（案の名前で持つ）。B）共有の値を、案ごとの「控え」に自動で出し入れする
  （AnyFlow の `VAR_AUTOSAVE`）。B は、つまみを触るとその場で選択中の案の控えを更新し、案を切り替える時は離れる案を控えてから選んだ案の控えを重ね、起動時は選択中の案の控えを当てる。
- 控えに入れるのは「その案が触る値だけ」（広すぎると別の設定を巻き込む）。**位置の移動・パディングも必ず入れる**（2026-09-20 に抜けていて連動した）。
- 隠した案・★・上書きの控えは、本体の設定とは別の入れ物に保存する（AnyFlow は `anyflow-gfx-presets`）。

**軸2　PC／スマホごと**
- スマホモード中にいじった値はスマホにだけ効き、PC の値は変わらない。PC でいじった値は、スマホで上書きした項目には出ない（STUDIO のレスポンシブ上書きと同じ考え方）。
- AnyFlow の作り：各つまみに「スマホ用の入れ物」を付ける（`mbKey` → `params.mb['値の場所']`）。スマホモード中はそこだけを読み書きする。スマホ実機（幅600px以下）は、起動時にスマホ用の値を本体へ流し込む。**案の値を当てた後に流す**（順番が逆だとスマホの値が案の値で戻る）。
- 文字（サイズ・太さ・行間・字間）は別の入れ物（`editsMb`）。**文字サイズだけはスマホが PC を引き継がない**（太さ・行間・字間は共通のデザインなので引き継ぐ）。
- スマホの既定値が PC と違う項目は、スマホの既定値を別に持てる（`mbDefault`）。PC 専用のつまみはスマホモード中に隠し、スマホ専用のつまみは PC で触っている間は隠す（2026-09-21）。
- **スマホ実機（幅600px以下）は見るだけ＝どこにも保存しない**（保存すると PC の値がスマホの値で汚れる）。PC⇄スマホの境目をまたいだら開き直し、その直前も保存しない（2026-09-26）。

**印とリセット**
- スマホモード中、スマホ用に上書きしている項目には**青い印**。触った瞬間に付く（元と同じ値でも）。左側の濃い青の帯や背景は付けない（2026-09-21）。
- スマホモード中の ↺ は「スマホの上書きを外す（PC の値に戻す）」だけ。PC の値は触らない。

**掛け合わせ**：案ごと×スマホ（例: 強調案のスマホだけ行間を変える）も独立させる（2026-09-25 の指示はこの形）。AnyFlow で掛け合わせまでできているのはビジョンの強調案の文字だけで、ほかのスマホの上書きは全部の案で共通（→ 食い違い一覧）。部品（v2.0.0）は掛け合わせまで独立（値は「案 × PC/スマホ」の組ごとに持つ・仮置き）。

**対象外（AnyFlow の仮置き）**：右グラフィックの動きの内部値（約50個。案ごとに持つのでスマホの上書きに載せていない）／慣性の強さ（表示と保存が逆向きの式）／実績の「固定の長さ」（入れ物が案で変わる）。

| 項目 | 部品 |
|---|---|
| 案ごとの独立（控えの自動の出し入れ） | ✅ 案ピルのあるタブ（まとまり）のつまみは既定で全部案ごと。`shared:true` だけ全案共通 |
| PC／スマホの独立（スマホ用の入れ物・起動時の流し込み） | ✅ スマホの上書きは `tp:<キー>:v<版>:mb`。起動時は案の値の後に流す |
| 青い印・スマホモード中の ↺ | ✅ 青い文字＋小さな●（左の帯・背景なし） |
| スマホ実機では保存しない | ✅ PC⇄スマホの境目をまたいだら開き直す（その直前も保存しない） |
| 案の控え（隠した案・★・上書き）を本体と別に保存 | ✅ `tp:<キー>:variants` |

## 🔴 必須要件（2026-08-21 ヒデさん制定）

**調整パネルと名の付くものは、どのプロジェクトでも必ず次の5点を備えること。**

1. **位置移動** … ヘッダーをドラッグして好きな場所へ動かせる
2. **サイズ変更** … 右下のつまみでリサイズできる（AnyFlow は上下左右の辺でも）
3. **たたむ／ひらく** … アコーディオンで折りたためる

4. **階層で整理する** … 項目を全部並列に並べない。**タブ＝ページのセクション**、その中は
   **カテゴリ**（バリエーション → 基本 → フォント → エフェクト＆テクスチャ → アニメーション）、
   カテゴリの中を**モノ（オブジェクト）の見出し**で束ねる（2026-09-20 AnyFlow で確定。→ 共通仕様 5）。
   例：`キービジュアル ＞ 基本 ＞ メッシュ ＞ 大きさ`

5. **切替で行を動かさない**（2026-08-26 ヒデさん指示・anyflow v2 で発覚／2026-09-14〜 改定）
   … 選択肢を切り替えた時に、**切り替えボタンとそれより上の行の位置が動いてはいけない**。
   - ◎ 案だけに効くつまみは、**その案を選んでいる時だけ出す**（2026-09-14〜26 ヒデさん指定。以前の「常に全部表示」は廃止）
   - ◎ 出し入れする部分は切り替えボタンのすぐ下に置き、その部分だけ見せる／隠す
   - ✕ 選択のたびにパネル全体を作り直す（どうしても作り直す時は、開いていた箱とスクロール位置を必ず保つ）

理由：パネルは調整したい対象（人物イラスト等）に重なりがちで、動かせないと
対象が見えない。項目が並列に並ぶと、増えるほど目的の場所を探せなくなる。
切替のたびに行が動くと、狙ったつまみを押し損ねて調整の手が止まる。
この tune-panel.js（v2.0.0）は 1〜5 を全部備えている（網走の React 版シェル `abashiri/v1`・`v2` の `components/TunePanel.tsx` は移動・リサイズ・たたむの3点）。
**素の div でパネルを自作しないこと。**

## 使い方（3ステップ）

### 1. 読み込む

```html
<script src="tune-panel.js"></script>
```

### 2. いじりたい値を1か所にまとめる

```js
const DEFAULTS = {
  common: { speed: 1 },
  orbit:  { variant: 'std', radius: 190, period: 9 },
  dot:    { size: 7, style: 'gradient' }
};
const params = structuredClone(DEFAULTS);   // 実際に描画で読むのはこっち
```

### 3. パネルを作る

```js
const panel = TunePanel.create({
  title: '調整パネル',     // 絵文字は付けない
  storageKey: 'my-app',   // 保存キー。プロジェクトごとに変える
  version: 1,             // 値の意味を変えたら上げる（古い保存値を自動で捨てる）
  params, defaults: DEFAULTS,
  // cat が2つ以上あればタブになる（タブ＝ページのセクション）

  schema: [
    { cat: '全体', items: [
      { sub: 'くり返し再生' },   // 見出しの言葉から「アニメーション」のカードに入る
      { slider: '再生速度', path: 'common.speed', min: 0, max: 2, step: 0.05, fmt: 'x',
        hint: '全部の動きの倍率。上げると速く、下げると遅くなる。' }
    ]},
    { cat: '軌道', items: [
      /* 見出しより前の案ピル＝このタブの主役の案。タブの中のつまみは、既定で全部「案ごと」 */
      { pills: '軌道の案', path: 'orbit.variant', options: [
        { name: '標準',   value: 'std', desc: 'カンプどおり。' },
        { name: '大きい', value: 'big', desc: '軌道を大きく。', values: { 'orbit.radius': 260 } }
      ]},
      { sub: '軌道の大きさ' },   // → 基本
      { slider: '大きさ', path: 'orbit.radius', min: 0, max: 380, step: 2, fmt: 'px',
        hint: '軌道の半径。上げると大きく、下げると小さくなる。' },
      { sub: '点の配色' },       // → エフェクト＆テクスチャ
      { seg: '配色', path: 'dot.style', options: [['グラデ', 'gradient'], ['2色', 'brand']],
        hint: '点の色の塗り方。' },
      { sub: '回転' },           // → アニメーション
      { slider: '1周の時間', path: 'orbit.period', min: 1, max: 17, step: 0.1, fmt: 's',
        hint: '1周にかける時間。上げるとゆっくり、下げると速く回る。' }
    ]}
  ],

  onSettle: () => replay()   // 手が止まって0.25秒後に1回だけ呼ばれる（切り替えは押した瞬間）
});
```

- 書いた順ではなく、タブの中は **バリエーション → 基本 → フォント → エフェクト＆テクスチャ → アニメーション → その他** に自動で並ぶ。
  振り分けは見出しの `grp`（`'basic'` `'font'` `'fxtex'` `'anim'` `'other'`）→ 無ければ見出しの言葉 → 中の項目名 の順で決まる（迷う所は `grp` を書く）。
- 範囲は自動（いまの値が真ん中・端で離すと取り直す）。書いた min は床（それ以上下げない値）と最初の幅の目安。0＝いまの位置の項目は `signed:true`、上限のある項目は `clamp:true`。
- 案ピルのあるタブのつまみは案ごとに独立（全案共通にしたい項目だけ `shared:true`）。スマホモードで触った値はスマホにだけ効く。

描画側は `params` を読むだけ。パネルは `params` を直接書き換えるので、
毎フレーム `params` を読む作り（requestAnimationFrame）なら**何も繋がなくても反映されます**。

見本: [`demo/index.html`](./demo/index.html)（タブ3つ・案ピル3案・案ごとの大見出し・各カテゴリのつまみ・案だけのつまみ・PC専用／スマホ専用・色・文字・2〜3択・チップ・名前つきの選ぶ行・まとまり・ボタン）。
開き方: このフォルダで `python3 -m http.server 8790` を動かして `http://localhost:8790/demo/` を開き、**右下の角**を押す（ファイルを直接開いても動くが、スマホモードのスマホ枠は localhost で開いた時がいちばん確実）。

### 保存の自動焼き込み（デプロイに引き継ぐ仕組み・2026-08-23 ヒデさん依頼）

> ※ AnyFlow V5／網走V3 の標準は「**設定書き出し**」ボタン → ファイルを Claude に渡して焼き込む形（共通仕様 8）。
> ここに書くのは網走V2 で作った別の方式（保存と同時に自動でファイルへ書く）。

localStorage の保存は**そのブラウザ・そのURL限り**で、デプロイには載らない。
そこで網走V2では「ローカルで💾保存 → デプロイで全員の既定値になる」を自動化した：

1. `onSave` フックで、ローカル（hostname が localhost）の時だけ全数値を `/api/tune-save` へ POST
2. 受け口（Next.js の API ルート）が `public/tune-defaults.json` に書き込む。**本番（VERCEL 環境変数あり）では 403 で拒否**
3. サイト側はパネル生成前に `/tune-defaults.json` を fetch し、初期値の形に合わせて重ねる（`shapeMerge`：知らないキー・型違いは捨てるので、古いファイルが残っても安全）
4. 上書きの優先順位は **コードの初期値 ＜ 焼き込みファイル ＜ そのブラウザの保存値**
5. JSON は git に載るので、次のデプロイで全員に反映される。`version` を上げてブラウザ保存が飛んでも焼き込みは残る

実装例は網走V2（`abashiri/v2/`）の `app/api/tune-save/route.ts` と `components/TopTunePanel.tsx`（shapeMerge・onSave）。
他プロジェクトに移植する時はこの3点セット（受け口・fetchマージ・onSave）をコピーする。

### メソッド

```js
panel.sync()             // params を外から書き換えた後、表示を合わせる（範囲も追いつく・出し入れも見直す）
panel.rebuild()          // schema を組み直す（開いていた箱・スクロール位置は保つ）
panel.save()             // すぐ保存（スマホ幅・スマホ枠の中では何もしない）
panel.show() / panel.hide() / panel.toggle()   // 出す / 隠す / 開閉
panel.setPhoneMode(true) // スマホモードにする（TunePanel.setPhoneMode でも同じ）
panel.setVariant('kv.variant', 'strong')       // 案を外から選ぶ（getVariant で読む）
panel.restoreVariants('kv.variant')            // 隠した案を全部まとめて戻す（画面の「↺ 消した案を戻す」は1つずつ）
panel.value('kv.copyX')  // いま画面に出ている値（スマホモード中はスマホで効く値）
panel.storageKeys()      // 保存に使っている localStorage のキー（PC の値・スマホの上書き・案の控え）
panel.phoneModeConfig()  // phone-mode.client.js に渡す設定のひな形
panel.reset()            // 全部を初期値に（画面のボタンは置かない）
panel.copy()             // 設定JSONをクリップボードへ
panel.importJSON(str)    // JSONを流し込む（「設定書き出し」のファイルの中身も読める）
panel.destroy()          // 消す
```

保存の中身: `tp:<キー>:v<版>`＝PC の値（今までと同じ形）／`tp:<キー>:v<版>:mb`＝スマホの上書き `{ 'a.b': 値 }`／`tp:<キー>:variants`＝案の控え `{ ver, hidden, fav, ov }`（`ov[案ピルのpath][案] = { pc:{…}, sp:{…} }`）／`tp:<キー>:ui`＝位置・大きさ・タブ・箱の開閉。
「設定書き出し」のファイルには、この全部と `__params`（PC の値そのもの）・`__mb`・`__variants` が入る。

### スマホモードと QR・実機への反映（phone-mode）

- 見出しの「📱 スマホモード」を押すと、スマホ用の値を触るモードになる（パネルの帯が青っぽく＋上に「スマホモード」の帯＋PC 上に 390×844 のスマホ枠）。もう一度押すと戻る。スマホ枠の × でも終わる
- スマホ枠の中は本物のページを `?tp-preview=1` で開いたもの。中のパネルは隠れて、保存されるたびにスマホの値で描き直す
- QR と、同じ Wi‑Fi のスマホ実機への反映も使う時は、パネルを作った**後**に [`phone-mode/phone-mode.client.js`](./phone-mode/) を読み込む。設定はパネルが作る:

```html
<script>
  window.PHONE_MODE_CONFIG = panel.phoneModeConfig();   // storageKeys・ボタン・帯の場所が入る（syncPort などは引数で上書き）
</script>
<script src="phone-mode.client.js"></script>
```

  これで同じボタンが「スマホモード＋QR の窓」になり（2回目の押下は QR の窓だけ閉じる）、保存のたびに中継サーバ（`phone-mode/server.mjs`）へ送られる。終える時は窓の「スマホモード終了」かスマホ枠の ×。
- つなぎきれない所（phone-mode 側のファイルは書き換えていない）: ①QR の窓は、クライアントが受け持つボタンからしか開け閉めできない（`phoneModeConfig()` の `headBtnSel` がパネルのボタンを指す）②クライアントの帯はパネルの帯と重なるので、部品の中では隠す ③実機側（`?live=phone`）は受け取るたびにページを開き直す（クライアントの作り。部品は実機では見るだけ・保存しない）④中継サーバの起動は今までどおり手で行う

### 「その場でリプレイ」の書き方

ライブラリはタイミングだけ担当します。**何を流し直すか**はアプリ側に書きます。

```js
TunePanel.create({
  …,
  onSettle: () => {
    // いま画面に映っているセクションだけ時計を巻き戻して流し直す
    for (const key in SECTIONS) {
      const r = SECTIONS[key].getBoundingClientRect();
      if (r.top < innerHeight && r.bottom > 0) resetSectionClock(key);
    }
    renderFrame();
  }
});
```

毎フレーム `params` を読んでいる作りなら、`onSettle` は空でもその場で反映されます。

## 🎯 スライダーは「既定値センター」で設計する（2026-08-23 ヒデさん制定・全プロジェクト共通／2026-09-27 改定）

**ツマミの初期位置（＝いまの値）がトラックの真ん中に来るようにする。上限と下限は大きく、細かくも大きくも動かせるように。**
「インジケーターはあるのに片方にしか動かせない」「動かしてもちょっとしか変わらない」を無くすため。
（2026-09-27 にヒデさんが改めて同じ内容を決め、刻みは「細かく」、範囲は **AnyFlow 式の自動の取り直し**に決めた。→ 共通仕様 0 の1・3）

1. **真ん中は自動**: 部品（v2.0.0）が「いまの値を真ん中、半幅＝いまの値−床」で範囲を決める。書いた min は床（それ以上下げない値）と最初の幅の目安、max は最初の幅の目安
2. **どこまでも広げられる**: 端（1割）で手を離すと、そこを真ん中に範囲を取り直す（狭くはしない）。外から値が変わって範囲を出た時も追いつく
3. **例外は2つだけ**:
   - 物理的な上限がある値（不透明度 0〜100% など）→ `clamp:true`（書いた範囲のまま）
   - 「0＝オフ」の項目（ブラー0など）→ 床が0なので下端が0でよい
4. **旧 `autoCenter`（max を自動で縮めて中央に見せる機能）は廃止**（渡されても何もしない）。
   上限が勝手に狭くなる事故（網走で5秒→1秒・2026-08-23）の元だったので、AnyFlow 式に置き換えた
5. **0＝いまの位置 のもの**（位置のずらし X/Y/Z・ギャップのずらしなど）は、`signed:true` を付けて 0 を真ん中にマイナス〜プラスで持つ（2026-08-28）
6. **刻みは細かく**（下の「刻み」のルール。2026-09-27 改定）

例: 既定1.6秒・`min:0.2` → 0.1〜3.1秒／既定100・`min:0` → 0〜200／位置のずらし 0・`signed:true, min:-300, max:300` → −300〜300

## 🔢 数値の持ち方ルール（2026-08-23 ヒデさん制定・全プロジェクト共通）

パネルに出す数値は、**Figma・CSS・ノーコードツールで普通に使われる単位と範囲**で持つ。
プログラム内部の流儀（0〜1の割合など）をそのままスライダーに出さない。

| 種類 | 持ち方 | fmt | 例 |
|---|---|---|---|
| 割合・透過率・音量 | **0〜100 の%** | `'%'` | 透過率 80（→「80%」と表示） |
| 大きさ・距離・位置 | px | `'px'` | 140（→「140px」） |
| 時間（1秒以上が普通のもの） | 秒 | `'s'` | 1.8（→「1.80s」） |
| 時間（1秒未満が普通のもの） | ミリ秒 | `'ms'` | 350（→「350ms」） |
| 角度 | 度 | `'deg'` | -8（→「-8°」） |
| 倍率（再生速度など） | 倍 | `'x'` | 1.5（→「×1.50」） |
| フォントウェイト | 100〜900（100刻み） | なし | 300 |
| 行間 | 倍数（CSSのline-height） | なし | 1.5 |

- **絶対にダメな例**：割合を 0〜1 で持ってスライダーに出す（「0.62」は直感的に読めない）。
  シェーダーなど内部が 0〜1 を要求する時は、**パネルは0〜100で持ち、渡す直前に ÷100 する**
- `'%'` の表示は互換のため自動判別が入っている（max が 1 以下なら100倍、それ以外はそのまま）。
  **新しく作る時は 0〜100 で持つこと**。自動判別は古いパネルを壊さないための保険
- 表示がおかしい時（6200%等）の原因はほぼこれ：値の持ち方と fmt の流儀の食い違い
- AnyFlow V5 は割合を中では 0〜1 のまま持ち、表示だけ100倍して % にしている所が多い（見える所は % なので見た目のルールは守れている）。
  新しく作る時は、この表どおり 0〜100 で持つ

## 🗣 用語の統一（パネルの言葉づかい・2026-08-23 ヒデさん制定／同日改定）

**2つのルール：**

1. **一般的なコーディング／ノーコードツール（Figma・Framer・Webflow・CSS）の標準用語を使う。**

2. **依頼時の言い回し（「スクロール深度」「尺」など）に合わせて毎回言葉を変えない。**
   既存の項目と違う言葉を使いそうになったら、まず既存のパネルを grep して合わせる

| 1周にかける時間 | **1周の時間**（duration） | s | 1周の速さ・スピード |
| 再生の倍率 | **再生速度**（playback rate） | × | スピード |
| スクロールの量・位置 | **スクロール量／〜の位置**（scroll offset / position） | px | 深度・深さ・尺・距離 |

## 🎚 刻み（step）と補足文（hint）のルール（2026-08-23 ヒデさん制定／刻みは 2026-09-27 改定）

**刻み：細かくする。** 範囲を広くとっても、細かい値にも大きい値にも合わせられるようにするため（2026-09-27 ヒデさん）。
目安は AnyFlow V5 のつまみで実際に使っている値（239本を数えた。書いた範囲のおよそ 1/50）。

- 位置・大きさ・余白（px）… **1〜2px**（数百pxある大きな距離でも **4px** 程度まで）
- 時間（秒）… **0.05秒**（0.01〜0.1秒の間）。ms なら **10〜50ms**
- 倍率 … **×0.05**（0.01〜0.1 の間）
- % … **1〜5%**
- 行間 … **0.05**
- ⚠️ 旧 `autoCenter` は **書いた上限を勝手に縮める**事故の元だった（網走で「max 5秒のはずが1秒までしか動かせない」2026-08-23）。
  v2.0.0 では廃止し、AnyFlow 式の自動の取り直し（端で離すとそこを真ん中に広げ直す）に置き換えた。書いた範囲で止めたい時は `clamp:true`

**補足文（hint）：次の2点を必ず書く。**

1. **この値が何を示しているのか**（どこの・何の値か）
2. **上げる／下げると何が変わるのか**（見た目にどう効くか）

> 例：「ボタンが出てから人物が登場するまでの待ち時間。上げると登場が遅くなり『間』ができ、下げるとすぐ出ます。」

書いた補足文は**画面には出さない**（縦に伸びて目的の行を探しにくくなるため。2026-08-27）。
項目名にマウスを乗せると吹き出しで読める形にする（AnyFlow は項目名の `title` に入れている）。部品（v2.0.0）も項目名の吹き出しに入れる（`keep:true` の時だけ行の下にも出す）。

## 覚えておくと事故らないこと

- **`version` を上げ忘れると壊れる。** 値の意味を変えたのに古い保存値が残ると、
  新しい初期値が上書きされて「自分だけ表示が違う」状態になる。上げれば古い値は自動で消える
- **重い処理は `onSettle` に置く。** `onChange` はスライダーを動かす間ずっと呼ばれる
- **`hint` は全行に書く。** 半年後の自分と、他の人のために効く（画面には出さず吹き出しで読ませる）
- **パネルの外寸は固定。** 中身で高さが伸び縮みすると、開閉のたびに触っている場所がズレる
  （anyflow-embed で実際に起きた。だからこのライブラリは外寸固定＋中身スクロールにしている）
- **スマホ幅（600px以下）で開いている間は、どこにも保存しない。** 保存すると PC の値がスマホの値で汚れる（共通仕様 7）
- **案を作り直しても「案ごと」「PC/スマホ別」の独立を消さない。** 作り直した時に抜けて連動する事故が何度も起きた（2026-09-19〜20）
- **1案だけ残すと、ピルと名前の行は隠れて「↺ 消した案を戻す (n)」だけが残る**（2026-09-27 ヒデさん決定。画面から戻せなくならないように）。コードから全部まとめて戻す時は `panel.restoreVariants('<path>')`
- **get / set を使う項目は、引数の params を使う**（スマホ実機では PC の値の控えが渡る。外の変数を直接読むとスマホの値が混ざる）
