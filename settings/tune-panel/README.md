# tune-panel

**作りながら数値をその場でいじれる「調整パネル」。**
JavaScript 1ファイル・依存ゼロ。どのページにも `<script>` 1行で足せます。

anyflow-embed のアニメ調整パネル（スライダー74本）を、どのプロジェクトでも使えるように
切り出したものです。

- 🎚 スライダー / 2〜3択 / ピル（案の切替）/ ON・OFF / プルダウン / 色 / 文字
- 🧭 大カテゴリのアコーディオン + 小見出し2階層 + 各行の補足文
- 🔍 検索ボックス（項目が増えても迷子にならない）
- 💾 `localStorage` に自動保存（次に開いても続きから）
- 📋 設定JSONの取り出しは `panel.copy()`（ボタンは撤去済み。Claude に貼れば既定値に焼き込める）
- 🎯 **ツマミの初期位置が自動で真ん中**（上げるも下げるもできる）
- 🖱 ヘッダーを掴んで移動 / 右下つまみでリサイズ / `.` キーで隠す（位置もサイズも保存）

---

## 🔴 必須要件（2026-08-21 ヒデさん制定）

**調整パネルと名の付くものは、どのプロジェクトでも必ず次の3点を備えること。**

1. **位置移動** … ヘッダーをドラッグして好きな場所へ動かせる
2. **サイズ変更** … 右下のつまみでリサイズできる
3. **たたむ／ひらく** … アコーディオンで折りたためる

4. **階層で整理する** … 項目を全部並列に並べない。カテゴリ（アコーディオン）は
   **ページまたは画面**、その中の小見出しは**セクション**、`deep` 見出しで**細目**、
   の3階層で設計する（AnyFlow のパネルで確立した構成。2026-08-21 網走で再徹底）。
   例：`🏠 トップページ ＞ 表情 ＞ 眉／口／確認用`

5. **切替でレイアウトシフトさせない**（2026-08-26 ヒデさん指示・anyflow v2 で発覚）
   … チップ／セグメント等で選択肢を切り替えた時に、**パネル内の項目の位置が動いてはいけない**。
   選択によって出すつまみを増減させる（パネルを作り直す）と高さが変わってガタつく。
   - ◎ 選択肢ごとのつまみは**常に全部表示**しておく（選んだ分だけ効く）
   - ◎ どうしても出し分けたい時は**高さを固定で確保**してから中身を入れ替える
   - ✕ 選択のたびに buildPanel() 等でパネル全体を作り直す

理由：パネルは調整したい対象（人物イラスト等）に重なりがちで、動かせないと
対象が見えない。項目が並列に並ぶと、増えるほど目的の場所を探せなくなる。
切替のたびに行が動くと、狙ったつまみを押し損ねて調整の手が止まる。
この tune-panel.js と、abashiri-site の components/TunePanel.tsx
（Reactシェル）は移動・リサイズ・たたむの3点を備えている。
**素の div でパネルを自作しないこと。**

## 使い方（3ステップ）

### 1. 読み込む

```html
<script src="tune-panel.js"></script>
```

### 2. いじりたい値を1か所にまとめる

```js
const DEFAULTS = {
  common: { speed: 1 },
  orbit:  { radius: 190, period: 9 },
  dot:    { size: 7, style: 'gradient' }
};
const params = structuredClone(DEFAULTS);   // 実際に描画で読むのはこっち
```

### 3. パネルを作る

```js
const panel = TunePanel.create({
  title: '⚙️ 調整パネル',
  storageKey: 'my-app',   // 保存キー。プロジェクトごとに変える
  version: 1,             // 値の意味を変えたら上げる（古い保存値を自動で捨てる）
  params, defaults: DEFAULTS,

  schema: [
    { cat: '🌊 全体', open: true, items: [
      { slider: '再生スピード', path: 'common.speed', min: 0.1, max: 3, step: 0.05, fmt: 'x',
        hint: '全部の動きが同じ倍率で速くなります。' }
    ]},
    { cat: '🛰 軌道', items: [
      { sub: '形' },
      { slider: '大きさ',   path: 'orbit.radius', min: 60, max: 420, step: 1, fmt: 'px' },
      { slider: '1周の秒数', path: 'orbit.period', min: 2,  max: 30,  step: .5, fmt: 's' },
      { pills: '配色', path: 'dot.style', options: [
        { name: 'グラデ', value: 'gradient', swatch: '#3fb7ff', desc: '青→ピンクへ変化。' },
        { name: '2色',    value: 'brand',    swatch: '#FF5D97', desc: '交互に2色。' }
      ]}
    ]}
  ],

  onSettle: () => replay()   // 手が止まって0.25秒後に1回だけ呼ばれる
});
```

描画側は `params` を読むだけ。パネルは `params` を直接書き換えるので、
毎フレーム `params` を読む作り（requestAnimationFrame）なら**何も繋がなくても反映されます**。

デモ: [`demo/index.html`](./demo/index.html) をブラウザで開く

## 部品の書き方

| 書き方 | 出るもの |
|---|---|
| `{ slider:'ラベル', path:'a.b', min, max, step, fmt, hint }` | スライダー |
| `{ seg:'ラベル', path, options:[['右回り',1],['左回り',-1]] }` | 2〜3択のボタン |
| `{ pills:'見出し', path, options:[{name,value,swatch,desc}] }` | 案の切替ピル（選択中の説明つき） |
| `{ toggle:'ラベル', path }` | ON / OFF スイッチ |
| `{ select:'ラベル', path, options }` | プルダウン |
| `{ color:'ラベル', path }` / `{ text:'ラベル', path }` | 色 / 文字 |
| `{ sub:'小見出し' }` / `{ sub:'…', deep:true }` | 見出し（deep で一段内側） |
| `{ note:'注釈' }` | グレーの補足文 |
| `{ button:'ラベル', onClick, primary:true }` | ボタン |
| `{ custom:(el, panel) => {…} }` | 自前のDOMを差し込む |

共通オプション

| キー | 意味 |
|---|---|
| `path` | `params` の場所を `'orbit.radius'` のように文字で指定 |
| `get` / `set` | `path` の代わりに関数で読み書きしたい時 |
| `fmt` | 値の見せ方。`'s' '%'  'px' 'deg' 'x' 'int' 'n1' 'n2'` か自前の関数 |
| `hint` | 行の下に出る薄いグレーの説明。**全部の行に書くのを推奨** |
| `when: p => p.core.show` | 条件付き表示（切替時は `rebuild:true` を併用） |
| `autoCenter: false` | ツマミの自動センタリングを切る（角度など、真ん中に意味がない値で使う） |

## パネル側のオプション

| キー | 既定 | 意味 |
|---|---|---|
| `storageKey` | なし | `localStorage` のキー。省略すると保存しない |
| `version` | `1` | **値の意味を変えたら上げる。** 古い保存値を自動で消す |
| `theme` | `'light'` | `'dark'` で暗いパネル |
| `position` / `size` | 右下 / 360×520 | 初期位置とサイズ |
| `startClosed` | `false` | たたんだ状態で出す |
| `search` | `true` | 検索ボックス |
| `hotkey` | `'.'` | 隠す / 出すキー。`null` で無効 |
| `saveMode` | `'button'` | **保存のしかた（Anyflowのパネルと同じ仕様）。** `'button'`: 触った値はその場で反映されるが保存はされず、未保存の変更があると「💾 保存」がピンクになる。押した時だけ localStorage に確定（リロード後も残る）。`'auto'`: 触るたびに自動保存（旧来の挙動） |
| `secret` | `true` | **隠しモード。** パネルは最初は見えず、画面右上の透明ボックス（64px）をクリックすると出る/隠れる。出した状態は同じタブの間だけ記憶。`false` で従来どおり常時表示（2026-08-21 ヒデさん指示で既定ON） |
| `settleDelay` | `250`(ms) | `onSettle` を呼ぶまでの「手が止まった」判定 |
| `footer` | `[]` | 足すボタン。既定は「💾 保存」「↺ リセット」の2つ（`footerDefaults:false` で消す） |
| `onChange(info)` | — | 動かすたび（毎フレーム相当）。**軽い処理だけ** |
| `onSettle(info)` | — | 手が止まって0.25秒後。**リプレイなど重い処理はこっち** |
| 項目のカスタマイズ | 自動 | **各項目のホバーで右上に「⠿並び替え」「🗑削除」が出る（2026-08-23 ヒデさん依頼）。** 🗑は確認モーダルを挟んでパネルから消す（サイトの動きは今の値のまま）。消した項目があるとフッターに「🗑 削除した項目を戻す(n)」が出て一括復活できる。⠿はドラッグで同じセクション内の並び替え。どちらも UI 状態としてそのブラウザに記憶される（`hidden` / `order`）。セクションをまたぐ移動は未対応（Claude に依頼してスキーマ側を並び替える） |
| `onSave(params, panel)` | — | 「💾 保存」を押した直後のフック。指定するとフラッシュ表示も自前になる（`panel.flash('...')` を呼ぶ）。**保存の自動焼き込み**（下記）に使う |

### 保存の自動焼き込み（デプロイに引き継ぐ仕組み・2026-08-23 ヒデさん依頼）

localStorage の保存は**そのブラウザ・そのURL限り**で、デプロイには載らない。
そこで網走V2では「ローカルで💾保存 → デプロイで全員の既定値になる」を自動化した：

1. `onSave` フックで、ローカル（hostname が localhost）の時だけ全数値を `/api/tune-save` へ POST
2. 受け口（Next.js の API ルート）が `public/tune-defaults.json` に書き込む。**本番（VERCEL 環境変数あり）では 403 で拒否**
3. サイト側はパネル生成前に `/tune-defaults.json` を fetch し、初期値の形に合わせて重ねる（`shapeMerge`：知らないキー・型違いは捨てるので、古いファイルが残っても安全）
4. 上書きの優先順位は **コードの初期値 ＜ 焼き込みファイル ＜ そのブラウザの保存値**
5. JSON は git に載るので、次のデプロイで全員に反映される。`version` を上げてブラウザ保存が飛んでも焼き込みは残る

実装例は abashiri-site-v2 の `app/api/tune-save/route.ts` と `components/TopTunePanel.tsx`（shapeMerge・onSave）。
他プロジェクトに移植する時はこの3点セット（受け口・fetchマージ・onSave）をコピーする。

### メソッド

```js
panel.sync()          // params を外から書き換えた後、表示を合わせる
panel.rebuild()       // schema を組み直す
panel.reset()         // 初期値に戻す
panel.copy()          // 設定JSONをクリップボードへ
panel.importJSON(str) // JSONを流し込む
panel.toggle()        // 開閉
panel.destroy()       // 消す
```

## 引き継いだ仕様（anyflow-embed で決めたこと）

このライブラリは思いつきで作ったものではなく、**anyflow-embed で実際に苦情が出て直した内容**を
そのまま持ってきています。対応状況は下の通り（ブラウザで実測して確認済み）。

| anyflow-embed で決めたこと | tune-panel | どこで |
|---|---|---|
| いじったら**その場でリプレイ**。ドラッグ中は重いので手が止まって0.25秒後 | ✅ | `onSettle`（`settleDelay:250`） |
| ピル・切替ボタンは**押した瞬間に即座に**流し直す | ✅ | `immediate:true` で即 `onSettle` |
| パネルを作り直しても**開いていたアコーディオンが閉じない** | ✅ | 開閉状態を記憶して復元 |
| 作り直しで**見ていたスクロール位置が先頭に飛ばない** | ✅ | `rebuild()` 前後で退避・復元 |
| **外寸を固定**して中身だけスクロール（開閉のたびに触る場所がズレない） | ✅ | 360×520 固定＋内部スクロール |
| パネル内のスクロールを**ページに伝播させない** | ✅ | `overscroll-behavior: contain` |
| **慣性スクロール(Lenis)にホイールを持っていかれない** | ✅ | `data-lenis-prevent` を自動で付与 |
| **ツマミの既定位置が自動で真ん中**（下げることもできる） | ✅ | `autoCenter`（既定ON） |
| 全スライダーに**補足文** | ✅ | `hint` |
| 小見出しの**2階層** | ✅ | `sub` / `sub:…, deep:true` |
| 選択中のピルの**説明文**を出す | ✅ | `options[].desc` |
| ヘッダーで移動 / 右下つまみでリサイズ / 位置とサイズを保持 | ✅ | ドラッグでは開閉を発火させない |
| **📋 いまの設定をコピー**（JSONを渡して既定値に焼き込む運用） | ✅ | フッターの既定ボタン |
| 保存値は初期値と**deep-merge**。壊れた値・知らないキーは捨てる | ✅ | `mergeSaved()` |
| **廃止した選択肢**が保存に残っていても事故らない | ✅ **改善** | options に無い値は初期値へ自動で戻す |
| 値の意味を変えたら保存キーのバージョンを上げる | ✅ **改善** | `version` を上げると古い保存を**自動で削除** |

> **改善** の2つは anyflow-embed では手作業だったところ（`STORAGE_KEY` を v56 まで手で上げていた）。

### 🧩 バリエーション行（案ピル）の共通仕様（2026-09-15 ヒデさん制定・全プロジェクト共通）

「案A / 案B / 案C…」のように**比較案を並べる行**は、どのプロダクト・どのセクションでも次の仕様にそろえる
（anyflow v4 の `varRowX()` が実装例。KV のバリエーション行で決めた仕様を全行へ広げたもの）。

| 仕様 | 中身 |
|---|---|
| **連番は「見えている順」に自動で振り直す** | 案を消すと 1,2,3… が詰まる（欠番を作らない）。元の ID は変えず、ボタンに乗せると `（ID 22）` のように出す。会話で案を指す時は「番号＋名前」か ID |
| **⋯ メニュー**（各ピルの右端） | ★ お気に入りにピン留め ／ ⤓ いまの設定で上書き ／ ↺ 上書きを解除 ／ 🗑 削除 |
| **★ お気に入り（ピン留め）は別枠** | 行の先頭（「おすすめ」枠）に ★1, ★2… の順で出し、通常の並びからは外す。解除で元の位置へ戻る |
| **⤓ いまの設定で上書き** | その案を選んだ時に「いまのつまみの値」を一緒に呼び出せるように控える（控えの範囲は行ごとに決める＝そのセクションの設定一式）。上書き済みは ⋯ から解除でき、解除するとコードの既定値へ戻る |
| **🗑 削除は「隠す」** | 一覧から消え、`↺ 消した案を戻す (n)` で 1 件ずつ戻せる。コードから恒久的に消す（完全削除）は「📋 完全削除リストをコピー」→ Claude に渡して焼き込む。コピーは**まだ焼き込んでいない案だけ**を出す |
| **「現行」は消せない・番号なし** | 既定（カンプどおり）は行の先頭に固定 |
| **案ごとのつまみは選んだ時だけ出す** | 案に固有の調整項目は、その案を選んでいる間だけ表示（動的グループ）。小見出しの「案◯」も番号に追従させる |
| **既定値の原本を守る** | 保存値と既定値の入れ子オブジェクトを共有しない（共有すると、つまみを動かした時に既定まで書き換わり「既定へ戻す」「上書き解除」が効かなくなる。2026-09-15 に実測で発覚） |
| **保存先** | 隠した案・★・上書きの控えは、本体の設定とは別の保管（anyflow では `anyflow-gfx-presets`）に持ち、本体と二重に持たない |

> tune-panel.js 側は `options` ピルまでの実装。上の ⋯ メニュー／★枠／連番／隠す・戻す／完全削除コピー は
> anyflow v4 の `varRowX()` を移植する（`settings/docs/anyflow/TASKS.md` 2026-09-15 参照）。

### 「その場でリプレイ」の書き方

ライブラリはタイミングだけ担当します。**何を流し直すか**はアプリ側に書きます。

```js
TunePanel.create({
  …,
  onSettle: () => {
    // いま画面に映っているセクションだけ時計を巻き戻して流し直す
    for (const key in SECTIONS) {
      const r = SECTIONS[key].getBoundingClientRect();
      if (r.top < innerHeight && r.bottom > 0) resetSectionClock(key);
    }
    renderFrame();
  }
});
```

毎フレーム `params` を読んでいる作りなら、`onSettle` は空でもその場で反映されます。

## 🎯 スライダーは「既定値センター」で設計する（2026-08-23 ヒデさん制定・全プロジェクト共通）

**ツマミの初期位置（＝既定値）がトラックの中央付近に来るように min / max を決める。**
「インジケーターはあるのに片方にしか動かせない」「動かしてもちょっとしか変わらない」を無くすため。

1. **中央設計**: `min ≒ 既定値 − 幅` / `max ≒ 既定値 + 幅`。既定値が端に張り付く範囲は作らない
2. **幅は大胆に**: 目安は既定値の±100%（時間なら倍〜半分より広く動かせる）。狭い範囲で「ちょっとしか変わらない」を作らない
3. **例外は2つだけ**:
   - 物理上限に既定が接する値（不透明度100%が既定など）→ 端でよい
   - 「0＝オフ」の項目（ブラー0など）→ 下端が0でよい
4. **`autoCenter`（maxを自動で縮めて中央に見せる機能）は使わない**（`autoCenter:false`）。
   上限が勝手に狭くなる事故のもと。**範囲そのものを広く設計して中央に置く**
5. 刻みは既存ルール（範囲の1/10〜1/20のキリのいい数）

例: 既定1.6秒 → `min:0.2, max:3.0, step:0.2`（1.6が中央）／既定100% → `min:0, max:200, step:10`

## 🔢 数値の持ち方ルール（2026-08-23 ヒデさん制定・全プロジェクト共通）

パネルに出す数値は、**Figma・CSS・ノーコードツールで普通に使われる単位と範囲**で持つ。
プログラム内部の流儀（0〜1の割合など）をそのままスライダーに出さない。

| 種類 | 持ち方 | fmt | 例 |
|---|---|---|---|
| 割合・透過率・音量 | **0〜100 の%** | `'%'` | 透過率 80（→「80%」と表示） |
| 大きさ・距離・位置 | px | `'px'` | 140（→「140px」） |
| 時間（1秒以上が普通のもの） | 秒 | `'s'` | 1.8（→「1.80s」） |
| 時間（1秒未満が普通のもの） | ミリ秒 | `'ms'` | 350（→「350ms」） |
| 角度 | 度 | `'deg'` | -8（→「-8°」） |
| 倍率（再生速度など） | 倍 | `'x'` | 1.5（→「×1.50」） |
| フォントウェイト | 100〜900（100刻み） | なし | 300 |
| 行間 | 倍数（CSSのline-height） | なし | 1.5 |

- **絶対にダメな例**：割合を 0〜1 で持ってスライダーに出す（「0.62」は直感的に読めない）。
  シェーダーなど内部が 0〜1 を要求する時は、**パネルは0〜100で持ち、渡す直前に ÷100 する**
- `'%'` の表示は互換のため自動判別が入っている（max が 1 以下なら100倍、それ以外はそのまま）。
  **新しく作る時は 0〜100 で持つこと**。自動判別は古いパネルを壊さないための保険
- 表示がおかしい時（6200%等）の原因はほぼこれ：値の持ち方と fmt の流儀の食い違い

## 🗣 用語の統一（パネルの言葉づかい・2026-08-23 ヒデさん制定／同日改定）

**2つのルール：**

1. **一般的なコーディング／ノーコードツール（Figma・Framer・Webflow・CSS）の標準用語を使う。**
   ネットで検索した時に引っかかる言葉が最優先。造語や身内の言い回しを発明しない
2. **依頼時の言い回し（「スクロール深度」「尺」など）に合わせて毎回言葉を変えない。**
   既存の項目と違う言葉を使いそうになったら、まず既存のパネルを grep して合わせる

| 概念 | 使う言葉（≒英語の標準用語） | 単位 | 使わない言い方の例 |
|---|---|---|---|
| 不透明度 | **不透明度**（opacity） | % | 透過率・薄さ・濃さ |
| ぼかし | **ブラー**（blur） | px | ボケ・にじみ |
| 開始までの待ち時間 | **ディレイ**（delay） | ms / s | 間・遅延・タイミング |
| アニメの所要時間 | **アニメーション時間**（duration） | ms / s | 出る時間・尺・かける時間 |
| くり返しの間隔 | **間隔**（interval） | s | 周期・サイクル |
| 1周にかける時間 | **1周の時間**（duration） | s | 1周の速さ・スピード |
| 再生の倍率 | **再生速度**（playback rate） | × | スピード |
| スクロールの量・位置 | **スクロール量／〜の位置**（scroll offset / position） | px | 深度・深さ・尺・距離 |
| カーソルを乗せる | **ホバー**（hover） | — | カーソルを乗せた時 |
| 文字の太さ | **フォントウェイト**（font-weight） | 100〜900 | 太さ・ウェイト単体 |
| 行の高さ | **行間**（line-height） | 倍数 | ラインハイト・行の間隔 |
| 文字の間隔 | **字間**（letter-spacing） | px | トラッキング |
| 大きさの倍率 | **スケール**（scale） | % / × | 拡大縮小 |
| 表示しておく時間 | **表示時間**（display duration） | s | 見せる長さ |
| 出現 | **登場** | — | 出方・出現（案ピルは「登場の案」） |
| 強さの度合い | **〜の強さ**（intensity/strength） | % | 量・レベル |

## 🎚 刻み（step）と補足文（hint）のルール（2026-08-23 ヒデさん制定）

**刻み：まず「ざっくり動かして全域を検証できる粗さ」にする。**
細かい刻み（50ms・1pxなど）はドラッグで違いが分からず検証がつらい。

- 目安は **範囲の 1/10〜1/20 の、キリのいい数**（1・5・10・50・100 / 0.5・0.25・0.1）
- 時間（秒）… **0.5s 刻み**が基本（1秒台の値なら 0.25s も可）。ms なら **100ms 刻み**
- スクロール量・大きな距離 … **100〜200px 刻み**。位置合わせ（ずれ調整）だけ 1px
- % … **5〜10% 刻み**
- 行間・倍率 … **0.1〜0.5 刻み**
- もっと細かく詰めたくなったら、その時に step を下げる（最初から細かくしない）
- ⚠️ **スキーマで min/max を決め打ちするパネルでは `autoCenter: false` を必ず指定する。**
  autoCenter（既定値を真ん中に置く自動調整）は、既定が範囲の下寄りだと
  **書いた上限を勝手に縮める**（max=既定×2 になる）。網走で「max 5秒のはずが1秒までしか
  動かせない」事故が起きた（2026-08-23）。anyflow でも同種の事故あり

**補足文（hint）：次の2点を必ず書く。**

1. **この値が何を示しているのか**（どこの・何の値か）
2. **上げる／下げると何が変わるのか**（見た目にどう効くか）

> 例：「ボタンが出てから人物が登場するまでの待ち時間。上げると登場が遅くなり『間』ができ、下げるとすぐ出ます。」

## 覚えておくと事故らないこと

- **`version` を上げ忘れると壊れる。** 値の意味を変えたのに古い保存値が残ると、
  新しい初期値が上書きされて「自分だけ表示が違う」状態になる。上げれば古い値は自動で消える
- **重い処理は `onSettle` に置く。** `onChange` はスライダーを動かす間ずっと呼ばれる
- **`hint` は全行に書く。** 半年後の自分と、他の人のために効く
- **パネルの外寸は固定。** 中身で高さが伸び縮みすると、開閉のたびに触っている場所がズレる
  （anyflow-embed で実際に起きた。だからこのライブラリは外寸固定＋中身スクロールにしている）

## 🗣 Claude に頼む時のプロンプト集（コピペ用）

このファイルを他のプロジェクト・他のClaudeアカウントに持っていけば、
下のプロンプトを貼るだけで同じ流儀のパネルが作れる／直せる。
**どのプロンプトでも「この README のルールに従って」と添えるのがコツ。**

### 情報整理サイクル（定期的に自主実行する）

> 調整パネルの構成を点検して。次の観点で整理・並び替えて：
> - **ページの流れ順か**：カテゴリ内のセクションは、画面に出てくる順（上→下）に並んでいるか
> - **同じ対象は1グループか**：同じ要素（人物・メッセージ等）の項目が離れた場所に散っていないか
> - **場所は適切か**：全ページに効くものは「サイト共通」、そのページ専用のものはそのページのカテゴリにあるか
> - **ルール適合か**：用語（語彙表）・数値の持ち方・刻み・hintの書き方がこのREADMEのルールに合っているか
> 整理したら version を上げて。

⚠️ このサイクルは**頼まれなくても自主的に回す**（ヒデさんルール 2026-08-23）。
目安：セクションを1つ足すか、項目を5つ以上足したら1回点検する。

### 新しくパネルを作る

> tune-panel/README.md のルールに従って、`tune-panel` を入れて下の値を調整パネルから触れるようにして。
> - storageKey は `<プロジェクト名>`、version は 1
> - カテゴリは「ページ ＞ セクション ＞ 細目」の3階層で整理（全部並列に並べない）
> - 全部の行に hint（非エンジニア向けのひとこと説明）を書く
> - 数値は README の「数値の持ち方ルール」どおり（%は0〜100、時間は秒かms、内部が0〜1でも渡す直前に変換）
> - 触ったらその場で反映。重い再描画は onSettle 側に
> - 保存は💾ボタン方式（触っただけでは保存されない）、パネルは隠しモード（右上の透明ボックス）

### 項目を足す

> 調整パネルに「◯◯」を足して。範囲は最小△〜最大□、既定は今の実装値。
> 単位は README の数値ルールに合わせて、hint も書いて。
> 既定値の意味が変わる場合は version を1つ上げて。

### 表示や数値がおかしい時（例：6200%になる）

> パネルの「◯◯」の表示が △△ になっていておかしい。
> tune-panel/README.md の「数値の持ち方ルール」に照らして、
> 値の持ち方（0〜1か0〜100か）と fmt の食い違いを調べて直して。
> 直したら、パネルの表示値を実測して「項目名：表示値」の一覧で報告して。

### 案ピル（比較案）を片付ける

> 「◯◯」は案△で確定。パネルの案ピルを撤去して既定値に焼き込み、
> パターン本体はコードに残して（後で1行で戻せるように）。version を上げて。

### アニメの値をその場で確認できるようにする

> 「◯◯」のアニメ系の値を変えたら、リロードせずその場で再生し直されるようにして。
> README の「その場でリプレイの書き方」を参照。
