### 仕組み（直す時に読む）

- **形**（`v3/js/slice.js` の `buildSlice`）: 厚み t の円盤。ふちは丸く（半径の 0.06）、上の面は少しふくらむ。上の面と丸みの境目の頂点は共有して、折り目の光の線を出さない。上の丸み＝上の面の模様（皮）、下の丸み＝下の面の模様
- **模様**（`sFace`）: 絵を貼らずに、元の輪切りの中の位置から計算する。外から 皮（0.935〜）→ わたの輪（0.895〜0.935）→ 明るい橙の帯（0.865〜0.895）→ 房の外側の細い線 → 房（11・不ぞろいな角度）。房の中は「地／明るい所／赤っぽい炎の形」の3色を、ぼかさずにはっきりした境目で塗り分ける（参考の塗り方）
- **色の出し方**: 明かりを「上の面・側面 ≒ 1、下を向いた面 ≒ 0.5」にして、色がほぼ設定した色のまま出るようにした。トーンマッピングは使わない（使うと白っぽくなる）。まわりの光の帯は映り込み（ツヤ）だけに使い、色の明るさには足さない（`uEnvDiffuse = 0`）
- **赤み**: 平らな面を上から見た角度では赤くせず、ななめに見える所（折れた所・ふち）ほど赤く深くする
- **ツヤ**: 上塗りのつるつるの層（clearcoat・くもり 0.025）に、細長い光の帯4本＋手前の大きな明かりを映す。帯は「平らな上の面に映らない向き」に置いてある
- **影**: 左奥の上からの明かり（高さ約37°）で、影は右手前へ。やわらかい影（VSM・ぼかし 26）を、影だけ見える透明な床に落とす（色 #190F00・濃さ 0.7）
- **ぷるぷる・折れ**（`v3/js/softslice.js`）: 輪切りを、重なり合った小さな部分（上から見て 0.3 おき・半径 0.55 の円柱）に分けて、部分ごとに元の形へ引き戻す。部分の間で曲がれるので、端をつまむと折れる。重みはなめらか（部分の境目にしわが出ない）。上の面と下の面の同じ所どうしの長さを保って、重さでつぶれないようにした（`keepThick`）
- **つかむ**（`SliceGrab`）: つまんだ所（半径の約0.14・厚み全部）を、決まった速さまでで指の位置へ動かす。つまんだ所は自由に回れる（調整パネル「つまんだ所の向きを保つ」で、指ではさんで持つ感じにもできる）。持ち上げる高さは、つまんだ所の高さ＋半径×0.55

## V2（3D）

2026-09-28 その3：ヒデさん「みかんのゼリーっぽいオブジェクトがあって、切ったら断面が見れる」「包丁もオブジェクトとして出して、角度を自由に変えられて、その通りに切れる」→ **最初に出るのは「みかんゼリー」＋「包丁」**。前の「ゼリーの中に果物」の3案は、調整パネルの案として残した。

### 操作

| 操作 | どうなる |
|---|---|
| 道具バー「きる」 | 包丁が出てきて、指（マウス）の所についてくる。テーブルに、刃が下りる所の線が出る |
| 　画面上の「向き」「傾き」 | 包丁の角度を変える（向き −180〜180°・傾き −60〜60°）。パソコンはホイール＝向き／Shift＋ホイール＝傾き／矢印キーでも回せる |
| 　タップ（クリック） | 離した所へ包丁をストンと下ろす。**刃の面のとおりに切れて**、2つが外へ倒れて断面が上を向く |
| 「さわる」で何も無い所からなぞる | 包丁が出てきて、なぞった線に沿って切る（向きはなぞった向き・傾きは「きる」で決めた角度） |
| ゼリーをタップ／押しっぱなし／押したまま動かす | ぷにっ／ぎゅっとへこむ／持ち上げて運ぶ（前と同じ） |
| 「ふやす」「ゆらす」「もどす」・右上・右下の角 | 前と同じ（みかんゼリーの時の「ふやす」はみかんだけ） |

### 案（調整パネルの「バリエーション」）

| 案 | 見た目 |
|---|---|
| **みかんゼリー（最初）** | まるごとのみかんの形をした、少し透けるゼリー。皮越しに房の筋がうっすら見える。切ると、切った向きに合った断面（外から 皮 → 白いわた → 房のつぶつぶ・房の間の白い薄皮・真ん中の芯）が出る |
| クリアゼリー／色つきゼリー／すりガラス寒天 | ゼリーの中に果物の輪切り（前の版） |

### 仕組み（直す時に読む）

- **形の記憶（3D）**: 表面の点（パソコン 1692個・スマホ 1002個）を、「いまの形にいちばん合う元の形の置き方」へ引き戻す（`v2/js/jelly.js` の `match`）。回転の取り出しは `v2/js/m3.js`
- **しわを作らない**: 元の形からのずれを、となりの点どうしでならす（`smooth`）
- **重力とテーブル・押し合い**: 床より下へ行かない／中を小さな玉で埋めて押し合う（`jellySpheres`）
- **切る**: 平面で表面を2つに分けて、切り口に平らなふた（`v2/js/cut.js`）。元の形・中の果物・当たり判定の玉も同じ平面で分ける（`World3D.cut`）。切ったら、それぞれの切り口が上を向く向きに回して倒す（`addSpin`）
- **包丁**（`v2/js/knife.js`）: 刃は三徳包丁の形。「向き」＝上から見た刃の向き、「傾き」＝刃を立てた状態からの傾き。**切る平面＝刃の面そのもの**で、下ろす時も刃の面に沿って動くので、見えている角度のとおりに切れる。刃の長さの中にあるゼリーだけ切る。切る直前に刃の近くを少し押し下げる（`pressBlade`）
- **みかんの断面**（`v2/js/mikan.js`）: 点ごとに「元のみかんの中のどこだったか」（`u0`）を覚えていて、切っても変わらない。色はそこから計算して決める（房10個・白い薄皮・芯・わた・皮）。切り口のふたには印（`aCap`）が付いていて、ふたは断面・それ以外は皮として描く。透け方も場所ごと（果肉はよく透け、皮・わたは少し）
- **みかんの質感**（2026-09-28・参考画像に寄せた）: ふちほど赤みを深くする（見る向きと面の向きの角度から）・中からほんのり光らせる（自分で光る量を少し足す）・上塗りのつるつるの層（clearcoat）。まわりの明かりを強くすると、オレンジが白っぽく飛ぶので 0.5倍にしている
- **透明感**: Three.js の透過の材質（transmission）。映り込みは撮影スタジオ風のまわりをゼリーと包丁だけに使う（`studioEnv`）。影は不透明の「かけ算」の板なので、ゼリー越しにも見える

## V1（2D）

### 操作

| 操作 | どうなる |
|---|---|
| 何も無い所から、果物をなぞって横切る | **切れる**（果汁が飛んで床にしみ。ゆっくりなぞると切りかけの筋が見える） |
| 果物をタップしてすぐ離す | **ぷにっ**（押した所から外へはじけて、波紋が広がる） |
| 果物を押しっぱなし | **ぎゅっとへこむ**（上から押されて横に広がる。中の種も指から逃げる）→ 離すとぷるるん |
| 果物を押したまま動かす | **つまんで移動**（少し持ち上がる。速く振ると伸びる。離すと投げられて、床でぽよん） |
| 道具バー「きる」 | どこからなぞっても切れる（果物だらけで空いた所が無い時用） |
| 「ふやす」 | 6種類（オレンジ・キウイ・いちご・すいか・レモン・ぶどう）から選んで落とす |
| 「ゆらす」／「もどす」／右上のボタン／画面右下の角 | V2 と同じ |

2本指で2つ同時に押す・動かすこともできる。

### 3案（調整パネルの「バリエーション」）

| 案 | 見た目 | 動き（最初の値） |
|---|---|---|
| ぷるぷるゼリー | 透けてツヤツヤ。床に果物の色の光が落ちる | 3.4回/秒でぷるぷる・長めに揺れる |
| もちもちグミ | 透けない。砂糖をまぶしたマットな面 | 4.6回/秒・揺れは短め・伸びにくい |
| 果物入り寒天 | 透明なゼリーの中に果物。後ろの方眼がゆがんで見える | 2.8回/秒・いちばん長く揺れる |

### 仕組み（直す時に読む）

- **形の記憶（シェイプマッチング）**: 果物のふちを点の輪で持ち、毎回「いまの形にいちばん合う元の形の置き方（中心・回転・伸び）」を計算して、各点をそこへ引き戻す。引き戻す強さ＝「ぷるぷるの速さ」。1回の計算は 1/240 秒（`v1/js/softbody.js` の `match`）
- **押す**: 押している間は、引き戻す先（元の形）を指の所から外へ広げる（`match` の中の press）
- **つかむ**: つまんだ所の近くの点ほど強く指へ引っぱる（`Grab`）
- **切る**: なぞった線でふちの輪を2つに分け、**形の記憶も同じ線で分ける**。中の模様（種・房・すじ）も同じ線で切り分ける（`splitBody`・`clipFeats`）。切り口の辺には「切り口」の印が付き、皮の色は付かない
- **模様がふちについてくる**: 中の点は「ふちの点の重み付き平均（平均値座標）」で持つので、ふちがゆがむと中もなめらかにゆがむ（`v1/js/geom.js` の `mvcWeights`）
- **押し合い**: 相手の中に入った点を、入ってきた時に横切った辺へ押し戻す。4分の1以上めりこんだら、中心どうしを少しずつ引き離す。壁ぎわではさまれて、へこんだまま0.8秒たったかけらは、0.5秒だけ当たり判定を外して形を戻す（絡まり防止・2026-09-28 に試験で直した。経緯は general/FIXLOG.md）
- 小さすぎる・薄すぎるかけら（面積 360px² 未満・平均の厚み 8px 未満）になる切り方はしない
