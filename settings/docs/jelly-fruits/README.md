# ぷるぷるフルーツ（jelly-fruits）

2026-09-28 新規。ゼリーでできた果物の輪切りを、**切る・つまんで動かす・ぷにぷに押す**ための画面（ゲームではなくインターフェース）。
カンプなし（場面B）で作ったので、配色・大きさ・動きの数値は**全部仮置き**。

- ローカル: http://localhost:8783 （`.claude/launch.json` の name: `jelly-fruits`。同じ Wi‑Fi のスマホからは `http://<このMacのIP>:8783`）
- 未デプロイ（「デプロイ」と言われたら新しい Vercel プロジェクトを作る）
- 依頼の台帳: [TASKS.md](TASKS.md)

## 操作

| 操作 | どうなる |
|---|---|
| 何も無い所から、果物をなぞって横切る | **切れる**（果汁が飛んで床にしみ。ゆっくりなぞると切りかけの筋が見える） |
| 果物をタップしてすぐ離す | **ぷにっ**（押した所から外へはじけて、波紋が広がる） |
| 果物を押しっぱなし | **ぎゅっとへこむ**（上から押されて横に広がる。中の種も指から逃げる）→ 離すとぷるるん |
| 果物を押したまま動かす | **つまんで移動**（少し持ち上がる。速く振ると伸びる。離すと投げられて、床でぽよん） |
| 道具バー「きる」 | どこからなぞっても切れる（果物だらけで空いた所が無い時用） |
| 「ふやす」 | 6種類（オレンジ・キウイ・いちご・すいか・レモン・ぶどう）から選んで落とす |
| 「ゆらす」 | お皿をゆらす（全部がぴょんと跳ねてぷるぷる） |
| 「もどす」 | 最初の並びに戻す |
| 右上のボタン | 効果音のオン／オフ |
| 画面右下の角（透明） | 調整パネルを出す／隠す |

2本指で2つ同時に押す・動かすこともできる。

## 3案（調整パネルの「バリエーション」）

| 案 | 見た目 | 動き（最初の値） |
|---|---|---|
| ぷるぷるゼリー | 透けてツヤツヤ。床に果物の色の光が落ちる | 3.4回/秒でぷるぷる・長めに揺れる |
| もちもちグミ | 透けない。砂糖をまぶしたマットな面 | 4.6回/秒・揺れは短め・伸びにくい |
| 果物入り寒天 | 透明なゼリーの中に果物。後ろの方眼がゆがんで見える | 2.8回/秒・いちばん長く揺れる |

## 仕組み（直す時に読む）

- **形の記憶（シェイプマッチング）**: 果物のふちを点の輪で持ち、毎回「いまの形にいちばん合う元の形の置き方（中心・回転・伸び）」を計算して、各点をそこへ引き戻す。引き戻す強さ＝「ぷるぷるの速さ」。1回の計算は 1/240 秒（`js/softbody.js` の `match`）
- **押す**: 押している間は、引き戻す先（元の形）を指の所から外へ広げる（`match` の中の press）
- **つかむ**: つまんだ所の近くの点ほど強く指へ引っぱる（`Grab`）
- **切る**: なぞった線でふちの輪を2つに分け、**形の記憶も同じ線で分ける**。中の模様（種・房・すじ）も同じ線で切り分ける（`splitBody`・`clipFeats`）。切り口の辺には「切り口」の印が付き、皮の色は付かない
- **模様がふちについてくる**: 中の点は「ふちの点の重み付き平均（平均値座標）」で持つので、ふちがゆがむと中もなめらかにゆがむ（`js/geom.js` の `mvcWeights`）
- **押し合い**: 相手の中に入った点を、入ってきた時に横切った辺へ押し戻す。4分の1以上めりこんだら、中心どうしを少しずつ引き離す。壁ぎわではさまれて、へこんだまま0.8秒たったかけらは、0.5秒だけ当たり判定を外して形を戻す（絡まり防止・2026-09-28 に試験で直した。経緯は general/FIXLOG.md）
- 小さすぎる・薄すぎるかけら（面積 360px² 未満・平均の厚み 8px 未満）になる切り方はしない

## ファイル

| ファイル | 中身 |
|---|---|
| `jelly-fruits/index.html` | 画面の骨組み（道具バー・トレイ・音ボタン） |
| `jelly-fruits/css/style.css` | 道具バーなどの見た目（数値は4と8の倍数・トークンは `:root`） |
| `jelly-fruits/js/main.js` | 指の操作・道具バー・調整パネルの中身（`DEFAULTS` が初期値）・毎フレームの流れ |
| `jelly-fruits/js/softbody.js` | ぷるぷるの物理（形の記憶・押し合い・つかむ・押す・切る） |
| `jelly-fruits/js/fruits.js` | 果物6種の形・模様・配色（`FRUITS`） |
| `jelly-fruits/js/render.js` | 描画（テーブル・影・色の光・ツヤ・皮・切り口・へこみ・波紋・ナイフの跡） |
| `jelly-fruits/js/effects.js` | 果汁のしぶき・床のしみ |
| `jelly-fruits/js/audio.js` | 効果音（その場で作る・音のファイルなし） |
| `jelly-fruits/tune-panel.js` | 共通の調整パネル（`settings/tune-panel/tune-panel.js` v2.1.0 のコピー） |
