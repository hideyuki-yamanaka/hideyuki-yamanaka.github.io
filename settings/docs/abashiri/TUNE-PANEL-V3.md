# 網走サイト V3.0 の調整パネル（anyflow 仕様に統一）

2026-09-16 ヒデさん依頼「調整パネルの仕様を anyflow のものに合わせて。
基本は anyflow の調整パネルを使って、中身は網走のコンテンツ」に対応した記録。

実体は [abashiri/v3/public/tune-panel.js](../../../abashiri/v3/public/tune-panel.js)。
網走サイトの**本番の画面に出るパネルはすべてこれ1本**
（トップページ＝[TopTunePanel.tsx](../../../abashiri/v3/components/TopTunePanel.tsx)、
スポット詳細＝[SpotDetailPage.tsx](../../../abashiri/v3/components/SpotDetailPage.tsx)）。

## 何ができるパネルか（anyflow と同じもの）

| できること | 前 | いま |
|---|---|---|
| 既定の大きさ | 幅360 | **幅450×高さ520**（anyflow と同じ） |
| 大きさを変える | 右下のつまみだけ | **上下左右の辺も掴める**（右下つまみも残る） |
| 大カテゴリ | タブ | タブ（変更なし） |
| 中の見出し | 開きっぱなし | **見出しごとにたためる**（閉じた所だけ記憶） |
| 項目ごとに元に戻す | なし | **各行に ↺**（その項目だけ最初の値へ。全体リセットの巻き添えがない） |
| プリセット | なし | **いまの値に名前を付けて保存・呼び戻し・上書き・改名・削除** |
| スマホ | 右下に小さく浮く | **下からせり上がるシート**（画面幅いっぱい・上の角丸） |
| 項目の削除・並び替え | あり | あり（変更なし） |
| 検索 | あり | あり（※ anyflow には無い。網走の方が便利なので残した） |
| 保存のしかた | 💾保存ボタン方式 | 同じ（変更なし） |
| 隠しモード | 右上の透明ボックス | 同じ。**スマホだけ、パネルが出ている間は上に逃げる**（保存・リセットと重なるため） |

## 使い方のポイント

- **パネルを出す**：画面右上のなにも描かれていない四角（64px）をクリック。`.` キーでも出る
- **プリセット**：下の「＋ いまの状態を保存」で名前を付けて保存。
  チップを押すと呼び戻し、`⋯` から上書き・改名・削除。
  ⚠️ 呼び戻した直後は**まだ保存されていない**ので、確定したいときは 💾 保存を押す
- **↺（各行）**：行にマウスを乗せると右上に出る。その項目だけ最初の値に戻る
- 保存先はブラウザの localStorage。本番に焼き込むのは `public/tune-defaults.json`

## 実測（2026-09-16）

| 確認したこと | 結果 |
|---|---|
| 既定幅 | 450px |
| 四辺のつまみ | 4個。左の辺を80px引っぱると 幅+80・位置-80（＝辺が動く） |
| たためる小見出し | トップページのタブで22個。押すと中身が display:none |
| 行ごとの↺ | トップページ67個／詳細ページ1個。500→507に動かして押すと500へ復帰 |
| プリセット | 保存→値を変更→呼び戻しで元の値に復帰。⋯メニューは上書き/改名/削除の3つ |
| スマホ(375px) | 幅375・下端固定・角丸14px（上のみ）・辺のつまみ非表示 |
| スマホの透明ボックス | パネル非表示時は右下、表示中は右上へ退避（パネルと重なり0） |
