## 🔴 並び順の基本ルール（2026-09-16 ヒデさん指定・全プロジェクト共通）

**調整パネルの項目・まとまりは、そのページのコンテンツが並んでいる順（画面の上から下）に置く。**
依頼が来た順に末尾へ足していかない。

> きっかけ：「指示があったものを何も考えずに調整パネルの下に追加していっている感じがある。
> フッターの項目が一番上に来ているが、フッターは一番下にあるので下に入れる」

- 新しい項目を足す時は、**末尾ではなくコンテンツ順の位置へ差し込む**
- 全ページ共通のタブの中も同じ考え方。
  画面全体の演出（環境音・ページ遷移）→ 画面の上に出るもの（カモメ）→ **フッターは最後**
- 番号付きの見出し（①②③…）は番号どおりに並べる
- 横に並ぶ要素（左のコピーと右のグラフィックなど）は読み順＝左→右

### この並びに直した記録（2026-09-16）

| タブ | 直す前 | いま |
|---|---|---|
| 🌐 サイト共通 | フッター → ページ遷移 → 環境音 → カモメ | **環境音 → ページ遷移 → カモメ → フッター** |
| 🏠 トップページ | メッセージ → カモメ → スポット → グルメ → 体験 → 人物イラスト | **人物イラスト → カモメ → メッセージ → スポット → グルメ → 体験** |
| 🎬 ぼーっと体験 | 導入 → 場所えらび → 動画 → カモメ | **導入 → カモメ → 場所えらび → 動画** |

※ 人物イラストとカモメはキービジュアルの中にいるので先頭。フッターは全ページの最後にあるので最後。

## 何ができるパネルか（見た目の側）

## 使い方のポイント

- **パネルを出す**：画面**右下**のなにも描かれていない四角（72px）をクリック。`.` キーでも出る
  - 2026-09-16 に PC・スマホとも右下へ統一（それまで PC は右上）。パネル本体も右下に出る
  - パネルが**出ている間だけ**、この四角は右上へ逃げる。
    右下に居座ると「書き出す」ボタンやサイズ変更のつまみに重なって、押したつもりが閉じてしまうため
- **プリセット**：下の「＋ いまの状態を保存」で名前を付けて保存。
  チップを押すと呼び戻し、`⋯` から上書き・改名・削除。
  ⚠️ 呼び戻した直後は**まだ保存されていない**ので、確定したいときは 💾 保存を押す
- **案の「⋯」**：ピルの右の三点。★ピン留め／⤓いまの設定で上書き／↺上書きを解除／🗑削除
  - **⤓ 上書き**＝その案を選んだ時に、**いまのつまみの値ごと**再現するようになる
  - **🗑 削除**＝一覧から隠すだけ。「↺ 消した案を戻す」から1つずつ戻せる
  - コードから**恒久的に**消すには「📋 完全削除リストをコピー」して Claude に渡す
- **↺（各行）**：行の右端に常に出ている。その項目だけ最初の値に戻る
- **↺（見出しの枠付き）**：そのまとまりの中を、ひとまとめに最初の値へ戻す
- **グレーの補足説明は既定で出ない**（anyflow と同じ）。見出しにマウスを乗せると吹き出しで読める。
  常に出したい所は、項目に `keep: true` を付ける
- 保存先はブラウザの localStorage。本番に焼き込むのは `public/tune-defaults.json`

### 途中で見つけて直した不具合

| 症状 | 原因 | 直し方 |
|---|---|---|
| ピン留め・削除がリロードで消える | 古いバージョンの保存値を掃除する処理が `tp:<キー>:v` の**前方一致**だったため、`:variants`（案の隠し・ピン留め）まで毎回消していた | 数字つきのバージョン鍵 `:v数字` だけを対象にする正規表現へ |
| 検証で本番の焼き込みファイルが書き換わった | ローカルでは「これをデフォルトに設定」が `tune-defaults.json` へ自動保存する。自動テストでこのボタンを押していた | ファイルを元に戻し、以降のテストではこのボタンを押さない（値の確認は別の手段で） |
