# 網走サイト V3.0 の調整パネル（anyflow 仕様に統一）

2026-09-16 ヒデさん依頼「調整パネルの仕様を anyflow のものに合わせて。
基本は anyflow の調整パネルを使って、中身は網走のコンテンツ」に対応した記録。

実体は [abashiri/v3/public/tune-panel.js](../../../abashiri/v3/public/tune-panel.js)。
網走サイトの**本番の画面に出るパネルはすべてこれ1本**
（トップページ＝[TopTunePanel.tsx](../../../abashiri/v3/components/TopTunePanel.tsx)、
スポット詳細＝[SpotDetailPage.tsx](../../../abashiri/v3/components/SpotDetailPage.tsx)）。

## 何ができるパネルか（anyflow と同じもの）

| できること | 前 | いま |
|---|---|---|
| 既定の大きさ | 幅360 | **幅450×高さ520**（anyflow と同じ） |
| 大きさを変える | 右下のつまみだけ | **上下左右の辺も掴める**（右下つまみも残る） |
| 大カテゴリ | タブ | タブ（変更なし） |
| 中の見出し | 開きっぱなし | **見出しごとにたためる**（閉じた所だけ記憶） |
| 項目ごとに元に戻す | なし | **各行に ↺**（その項目だけ最初の値へ。全体リセットの巻き添えがない） |
| プリセット | なし | **いまの値に名前を付けて保存・呼び戻し・上書き・改名・削除** |
| スマホ | 右下に小さく浮く | **下からせり上がるシート**（画面幅いっぱい・上の角丸） |
| 項目の削除・並び替え | あり | あり（変更なし） |
| 検索 | あり | あり（※ anyflow には無い。網走の方が便利なので残した） |
| 保存のしかた | 💾保存ボタン方式 | 同じ（変更なし） |
| 隠しモード | 右上の透明ボックス | 同じ。**スマホだけ、パネルが出ている間は上に逃げる**（保存・リセットと重なるため） |

## 使い方のポイント

- **パネルを出す**：画面右上のなにも描かれていない四角（64px）をクリック。`.` キーでも出る
- **プリセット**：下の「＋ いまの状態を保存」で名前を付けて保存。
  チップを押すと呼び戻し、`⋯` から上書き・改名・削除。
  ⚠️ 呼び戻した直後は**まだ保存されていない**ので、確定したいときは 💾 保存を押す
- **↺（各行）**：行の右端に常に出ている。その項目だけ最初の値に戻る
- **↺（見出しの枠付き）**：そのまとまりの中を、ひとまとめに最初の値へ戻す
- **グレーの補足説明は既定で出ない**（anyflow と同じ）。見出しにマウスを乗せると吹き出しで読める。
  常に出したい所は、項目に `keep: true` を付ける
- 保存先はブラウザの localStorage。本番に焼き込むのは `public/tune-defaults.json`

## 実測で突き合わせた表（2026-09-16）

anyflow と網走のパネルを**同じ条件で 2倍解像度で撮影**し、
各パーツの computed style を吸い出して数値で比較した。

### 見た目の数値

| 部品 | 項目 | anyflow | 網走(前) | 網走(いま) |
|---|---|---|---|---|
| パネル全体 | 地 | `rgba(255,255,255,.92)` | `.93` | **一致** |
| | 枠 | `1px #ececec` | `1px #e2e2e2` | **一致** |
| | 角丸 | 8px | 10px | **一致** |
| | 文字 | 11px | 12px | **一致** |
| ヘッダー | padding | 14px 12px | 10px 12px | **一致** |
| | タイトルの太さ | 400 | 500 | **一致** |
| タブの帯 | 位置 | 上に貼り付く | 貼り付かない | **一致** |
| | 地／ぼかし | `rgba(255,255,255,.96)` / blur6 | 透明 | **一致** |
| | 下の区切り線 | あり | なし | **一致** |
| タブ | 高さ | 26px | 30.5px | **一致** |
| | 角丸 | 13px（丸いピル） | 8px | **一致** |
| | 幅 | 内容ぶん | 均等割り | **一致** |
| | 文字 | 11.5px／行送り24px | 11px／16.5px | **一致** |
| | 選択時の黒 | `#111` | `#090909` | **一致** |
| 本文 | padding | 0 10px 10px | 0 12px 12px | **一致** |
| 小見出し | 文字 | 11.5px／500／`#666` | 11px／400／`#555` | **一致** |
| | 下の余白 | 4px | 6px | **一致** |
| 行 | 項目の間 | 6px | 8px | **一致** |
| | 上下の余白 | 2px | 4px | **一致** |
| ラベル | 幅 | 100px | 92px | **一致** |
| 数値 | 幅 | 48px | 46px | **一致** |
| 入れ子 | margin/padding | 7px ／ 6px 0 0 8px | 8px ／ 8px 0 0 10px | **一致** |
| プリセットのラベル | 文字 | 11px | 10px | **一致** |

> 14部品のうち **11部品が数値まで完全一致**。残る3つは意図的な差：
> ①ヘッダーの `gap`（網走は gap、anyflow は margin-left:auto。見た目は同じ）
> ②タイトルの `overflow:hidden`（網走はタイトルが長いので「…」で省略する）
> ③`.tp-grp` の採寸対象が入れ子かどうかの違い（値そのものは anyflow と同じ）

### 組み方・見せ方

| 部品 | anyflow | 網走(前) | 対応 |
|---|---|---|---|
| タブの中のセクション | 箱で囲まず区切り線だけ | 白い箱＋枠＋角丸 | **箱をやめて区切り線に** |
| 行ごとの ↺ | 常に見えている | ホバー時だけ | **常時表示に**（⠿🗑はホバーのまま） |
| まとまりの ↺ | 見出しの右に枠付きで | なし | **追加**（中の項目をまとめて戻す） |
| グレーの補足文 | 既定で出さない | 全部出していた | **既定で隠す**。見出しにマウスを乗せると吹き出しで読める |
| 数値の破線（直接入力の印） | なし | 常時 | **行に触れた時だけ** |
| たたんだ時の添え書き | 「クリックで開く」 | なし | **追加** |
| ヘッダーを押す | 開閉する | 何も起きない | **開閉する**（3px以上動かした時は移動として扱う） |

## 残っていること 🟡

- **anyflow にある「✏️ 編集」モードは入れていない。**
  サイト上の要素を直接ドラッグして動かせる機能で、網走には同等の仕組みがない。
  入れるなら別途まとまった作り込みがいるので、**やるかどうかの判断待ち**
- **共通キット [settings/tune-panel/tune-panel.js](../../tune-panel/tune-panel.js) は古いまま。**
  網走のコピー（`abashiri/v3/public/tune-panel.js`）だけが新仕様。
  他プロジェクトにも配るなら、差分を共通キットへ戻す作業が別途いる
- `/mock/` の比較ページだけは、昔の簡易な React 版シェル
  （`components/TunePanel.tsx`）を使っている。本番の画面ではないのでそのままにしてある
