## 0. 数値の丸めルール（ヒデさん指定 2026-08-22）

- **基本は偶数。4の倍数・8の倍数を優先**
- **10px 以下は 2 の倍数を許容**（4・8 に揃えられない小さい値）
- 字間（tracking）だけはカンプの指定値をそのまま使う（0.4px / 0.7px。書体の見え方に直結するため）

**丸めの対象**は「文字サイズ」と「要素同士の間隔（gap・margin・padding）」。
**カンプ採寸の位置座標**（left / top など、画面上の置き場所そのもの）は丸めの対象外
（丸めると絵がずれるだけで統一の意味がないため）。

カンプ・旧実装の端数をこのルールで丸めた対応表（サイト全体）：

| 箇所 | 旧値 | 採用値 | 理由 |
|---|---|---|---|
| グルメカードの幅 | 586.73px | **588px** | 4の倍数 |
| グルメカードの高さ | 504.38px | **504px** | 8の倍数 |
| 「もっと見る」の文字（グルメ・スポット共通） | 17px | **16px** | 偶数化＋Body_16px に統一 |
| メッセージ見出しの上位置 | 172.48px | **172px** | 4の倍数 |
| ナビ項目の間隔 | 42px | **40px** | 8の倍数 |
| 体験導入 見出しと本文の間 | 77px | **76px** | 4の倍数 |
| 体験導入 段落の間 | 33px | **32px** | 8の倍数 |
| スポットのサムネイル間 | 14.4px | **16px** | 8の倍数 |
| 環境音モーダルの文字（Body_15） | 15px | **16px** | 偶数化＋Body_16px に統一 |

## 1. カラー

**V1.0 から変更なし。** Brand_Primary(#0070c9)・Sky グラデ・Text_Default ほか
[DESIGN-SYSTEM.md](DESIGN-SYSTEM.md) の定義をそのまま使う。

V2 で増えた「名前を持たせない色」：

- グルメカードのホバー幕 … `rgba(0,0,0,0.2) → rgba(0,0,0,0.8)` の縦グラデ（黒。写真の上に文字を置くための幕なので、青の Shadow_Base ではなく黒）
- メッセージ見出しの白 … `white / 80%`（Hero_90px 専用の透過）

## 2. テキスト

### 書体とウェイト（V2 は Noto Sans JP の 4 ウェイト）

| ウェイト | 使いどころ |
|---|---|
| **Thin (100)** | 大見出し全般（Hero_90 / Title_44 / Title_36 / Title_28） |
| **ExtraLight (200)** | カードの小見出し・説明・「もっと見る」 |
| **Light (300)** | 読ませる本文（メッセージ本文・ナビ） |
| **Medium (500)** | ボタンの文字（「ぼーっとしてみる」等） |

数字は Inter（V1 と同じ）。Zen Kaku / M PLUS Rounded は V1 の残置セクションのみ。

### V2 で追加したサイズ

| トークン | px | ウェイト | 行間 | 字間 | 使いどころ |
|---|---|---|---|---|---|
| **Hero_90px** | 90 | Thin | 1 | — | メッセージ見出し「網走は何もない。」（白80%） |
| **Title_36px** | 36 | Thin | 1.8 | — | グルメの見出し（黒） |
| **Title_28px** | 28 | Thin | 1.2 | — | グルメカードの店名（白） |
| **Body_20px** | 20 | Light | 2 | 0.4px | メッセージ本文（白） |
| **Body_14px** | 14 | ExtraLight | 2 | 0.7px | カードの説明文（白） |

### 統一したもの（サイト全体）

- 「もっと見る」…… カンプの 17px を **Body_16px + ExtraLight** に統一（グルメ・スポット、黒・白どちらも）
- 小見出し「素朴なグルメ 01」「ぼーっとスポット 01」…… **Body_16px + ExtraLight**（cap 詰め）
- **Title_36px はグルメ見出しとスポット名の共通サイズ**（どちらも Thin）
- 説明文（グルメ・スポット）…… **Body_14px + ExtraLight・字間0.7px**。行間はグルメ2／スポット2.2（カンプ指定のまま）
- 環境音モーダル …… **Body_15px を廃止して Body_16px に統一**。V2 では Body_15px を使わない（トークンは V1 残置セクション用に globals.css に残っている）
- Control_14px（V1）と Body_14px（V2）は同じ 14px。V2 の読ませる説明文は Body_14px を使う

## 3. 角丸

**V2 の新セクション（メッセージ・グルメ）は角丸なし（0）。**
V1 の楕円カード（Radius_290px）はスポット・体験の旧部品にのみ残る。
新しくカードを作る時は「角丸なしの長方形」が V2 の基準。

## 4. 余白（V2 のスペーシング段階）

4・8 の倍数で構成。V2 の画面で実際に使っている段だけ登録する。

| 値 | 使いどころ |
|---|---|
| 4px | 「もっと見る」文字とアイコンの間 |
| 8px | カルーセルのカード間／小見出しと店名の間 |
| 16px | カード内 見出し行と説明文の間／ボタン上下パディング／スポットのサムネイル間 |
| 24px | カードのホバー幕 上下パディング |
| 32px | 体験導入の段落間／ナビの上位置 |
| 40px | メッセージ本文の段落間（= 行間2の1行ぶん）／ナビ項目の間隔 |
| 44px | カードのホバー幕 左右パディング／ボタン左右パディング |
| 76px | 体験導入 見出しと本文の間 |
| 100px | 体験導入 本文とボタンの間 |
| 120px | メッセージ見出しと本文の間 |
| 140px | グルメ見出しとカルーセルの間／メッセージの左端位置 |
| 172px | メッセージの上位置 |

位置座標（人物イラストの置き場・スポットのサムネ位置など、カンプ採寸の left/top）は
このスケールの対象外。カンプの値をそのまま使い、調整パネル／設定ファイルで管理する。

## 5. シャドウ・ブラー・モーション

V1.0 の定義を継承（Shadow 4種・Blur 段階・Ease_Standard）。
V2 で加わった動きのパラメーターはコード側の設定ファイルが正：

- 作字の登場 … `heroEnterConfig.ts`（ブラー9px・1450ms）
- 作字の消え方 … `kvExitConfig.ts`
- メッセージの出方 … `msgConfig.ts`（案1〜3・にじみ幅）
- 人物の登場／ホバー … `illustEnterPatterns.ts`（案3採用）／`hoverBouncePatterns.ts`
