# 網走サイト V3.0 調整パネルの構成ルール（2026-09-20）

> **anyflow V5.0 と同じルールで揃えてある。**ルールの本体は
> [anyflow/ANYFLOW-PANEL-STRUCTURE.md](../anyflow/ANYFLOW-PANEL-STRUCTURE.md)。
> ヒデさん指示（2026-09-20）「このプロダクトに関しても、anyflow と同じで、
> 基本・フォント とかいうやつ。並び順も anyflow と一緒です」。
> 新しく項目を足す時も、必ずこの順・この名前にする。独自カテゴリを作らない。

## 1. 第1階層：カテゴリ（全タブ共通・この順で固定）

| 順 | カテゴリ | 入るもの |
|---|---|---|
| ★ | **バリエーション** | 案を選ぶUI（開閉なしのプレーン大見出し） |
| 1 | **基本** | 位置(X/Y/Z)・余白(ギャップ/マージン/パディング)・大きさ・幅・高さ |
| 2 | **フォント** | 太さ・行間・字間・文字サイズ |
| 3 | **エフェクト＆テクスチャ** | 色・配色・光・影・ぼかし・質感・線 |
| 4 | **アニメーション** | 出現・ディレイ・順番・速さ・登場/退場/切替・再生時間 |
| 5 | **その他** | 上のどれにも収まらない暫定の置き場 |

実装: `public/tune-panel.js` の `GRP_ORDER` / `GRP_LABEL` / `grpFromLabel`。
節に `grp: "basic"` のように書くと、そのカテゴリへ入る。書かなければ名前から自動判定。

## 2. 第2階層：オブジェクト（モノ）で束ねる
同じモノに効く項目は、そのモノの見出しの下にまとめる。
1つのモノが複数カテゴリにまたがってよい（名前は必ず同一にする）。

## 3. 見た目（ミニマル）
- **絵文字は使わない**（タブ名も見出しも）
- **左のインデント縦線は使わない**（border-left 禁止）
- 階層は文字サイズ・太さ・余白で表す。区切り線は H1 のみ

実測値（2026-09-20）:

| 階層 | サイズ | 太さ | 左線 |
|---|---|---|---|
| H1 カテゴリ | 13px | 700 | 0px |
| H2 オブジェクト | 12px | 600 | 0px |
| H3 入れ子 | 11px | 400 | 0px |

## 4. 命名の統一
- 位置は **X / Y / Z**（「左からの距離」「上からの距離」は使わない）
- 余白は **ギャップ / マージン / パディング**（「距離」「間」は使わない）
- 見出しにモノ名があれば、子項目からモノ名を省く

## 5. 現在の割り当て（2026-09-20 実測）

| タブ | カテゴリ › 節 |
|---|---|
| サイト共通 | 基本 › フッター ／ エフェクト＆テクスチャ › カモメの見た目 ／ アニメーション › ヘッダーのアンカー移動・ページ遷移の演出 ／ その他 › 環境音 |
| トップページ | 基本 › 人物イラスト・カモメ ／ フォント › セクションの大見出し ／ アニメーション › メッセージ・ぼーっとスポット・グルメ・体験セクション |
| ぼーっと体験ページ | 基本 › カモメ ／ アニメーション › 導入メッセージ・場所えらび・動画まわり |

## 6. anyflow から移植した見た目（2026-09-20 実測で一致を確認）

| 箇所 | 値 |
|---|---|
| パネルのタイトル | 「**調整パネル**」15px / 700 / 字送り.02em / #1a1a1a（歯車アイコンなし） |
| タブ | アンダーライン型。12.5px / 600、選択中は #111＋下線2px。横スクロール（折り返さない） |
| H1 カテゴリ | 13px / 700 / 字送り.03em / #111。**上の横線は引かない** |
| H2 オブジェクト | 12px / 600 / #333 |
| H3 入れ子 | 11px / 400 / muted |
| 開閉アイコン | マテリアル `expand_more`（文字を透明にして mask で描画） |
| リセット | マテリアル `refresh`（同上）。行の右端に18px |
| 下部ボタン | **塗らない**。白地＋#d5d5d5 の線、11px。ホバーで #0EBBFF の線 |

### 下部ボタンの並びと名称（anyflow の言い回しに統一）
1. `💾 既定にする`（未保存があれば「（未保存あり）」を足す）
2. `⬇️ 設定を書き出す（Claudeに渡す）`
3. `📋 削除リストをコピー（Claudeに貼る）`

## 7. 命名（anyflow のルールを適用済み・2026-09-20）
- 「出てくる」概念はすべて **出現** に（登場ディレイ／表示ディレイ／開始ディレイ → 出現ディレイ）
- 見出しにモノ名があれば子から省く（「人物イラスト › 人物の登場ディレイ」→「出現ディレイ」）
- 区切りの `｜` は使わない（「表情｜眉」→「眉」）
- 位置は **X / Y / Z**、余白は **ギャップ／マージン／パディング**
- 案を選ぶUIの名前は **案**（「レイアウトの案」「登場の案」「遷移の案」→「案」）
