### ブラーの落とし穴（実測で分かったこと・2026-09-16）

1. **`backdrop-filter` は毎フレーム値を変えると極端に重い。**
   ページ遷移の演出では**ブラー量は固定**して、幕の不透明度だけを動かしている。
2. **`filter` / `backdrop-filter` が付いた要素は合成レイヤーになり、その縁が
   隣の同じ色のセクションとの境目に薄い線（ヘアライン）として出る。**
   `blur(0px)` や、アニメの残りかすの `blur(0.003px)` でも出る。
   → 対処は ①フィルターを外す ②`-mt-[2px]` で 2px 重ねる。フッターと体験セクションで実施済み。
3. **`position: fixed` の要素の上では backdrop-blur が効かないことがある。**
   ぼーっとタイマーはこれで一度効かなくなった。

## 6. レスポンシブの区切り

| 幅 | 出るもの |
|---|---|
| **900px 以下** | スマホ・タブレット用のレイアウト（`MobileTop` / `MobileExperience`） |
| **901px 以上** | PC の固定キャンバス（1512×982 を画面に合わせて拡大縮小） |

2026-09-16 に **640px → 900px** へ変更した。
理由：768px（タブレット縦）では PC のキャンバスが 0.51 倍まで縮み、
14px の文字が実質 7〜8px になって読めなかったため（実測）。
900px 区切りにすると 768px でも読みやすい方のレイアウトが出て、本文は 22px 相当になる。

**スマホ版は PC のスタイリングを踏襲する。**
スマホ専用のアレンジ（角丸を足す・文字を写真に直載せする等）はしない
（2026-09-16 ヒデさん指示）。キービジュアルの作字と「網走市観光サイト」の位置関係も、
PC と同じ相対座標のまま縮小して置く。

キービジュアルの作字ブロック（PC カンプ 415×379）は
**`MobileTop.tsx` の `KV_SCALE` 1か所だけで縮小率を持つ**（現在 **0.64**）。
枠の寸法もこの定数から計算しているので、片方だけ直すと中身と枠がずれる。
⚠️ 作字の画像（471×390）を 415px の枠に直接置くと、ブラウザ既定の
`img { max-width: 100% }` で 415px に切り詰められ、作字だけ約12%小さくなって
キャプションとの位置関係が崩れる。PC と同じく中間の div に逃がすこと。

## 7. シャドウ・モーション

V1.0 の定義を継承。

| トークン | 値 | 使いどころ |
|---|---|---|
| **Shadow_Illust** | `-8px 1px 2px rgba(0,95,179,.25)` | 切り抜きイラスト |
| **Shadow_Floating** | `0 8px 20px -6px rgba(0,95,179,.35)` | 浮いた小物 |
| **Shadow_Modal** | `0 25px 50px -12px rgba(0,95,179,.35)` | ダイアログ |
| **Ease_Standard** | `cubic-bezier(.22,1,.36,1)` | 動くものは全部これ（V3 で 32 か所） |

### スクロール演出の決まりごと（V3 で制定）

- **動かしてよいのは `transform` / `opacity` / `clip-path` だけ。**
  `width` / `height` を毎フレーム変えるとレイアウトが計算し直しになって
  ガタつく（体験セクションの「グラグラする」の原因はこれだった）。
- **いちばん良く見えるのは「画面の真ん中に来た時」。**
  スクロール進行度は 0＝下から入る／1＝上へ抜ける なので、**0.5 が画面中央**。
  `[0, 0.5] → [0, 1]` に読み替えて、中央で完成してそのまま保つ。
- **進行度の入力範囲は必ず 0〜1 の増加順**。マイナスを入れるとページが落ちる
  （WAAPI の "Offsets must be monotonically non-decreasing"）。

## 8. 運用

- 新しい数値が必要になったら、**まず上の表に近い段がないか探す**。
  あれば寄せる。無ければトークンを足してからコンポーネントで使う
- 直値（`text-[20px]` など）を書いたら、それは**トークンの登録漏れ**のサイン
- 値を変えた時は**住み家を全部直す**：
  ①コードの既定値 ②`TopTunePanel` の DEFAULTS ③`public/tune-defaults.json`（本番の焼き込み）
  ④ブラウザの localStorage（`version` を上げると古い保存値が捨てられる）
