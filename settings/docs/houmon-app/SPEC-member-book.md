> 決めた日: 2026-10-26（ヒデさんと質問しながら固めた）。作業場所: houmon-app の `update/member-book` ブランチ。
> 狙い: 家庭訪問アプリを軸にしたまま、「訪問しない人の情報も忘れないように残せる」メンバー情報のアプリにもする。
> 作りは「名簿は1つ・区分で分ける」「情報は決まった見出しに振り分ける」のシンプルな形にして、あとから広げやすくする。

## データの持ち方（2026-10-26 作った・SQL は `houmon-app/sql/2026-10-26-member-info-sections.sql`）

- メンバーに `info_sections`（jsonb 1つ）を足す：`{ family: [文], trait: [文], event: [{date, text}], other: [文] }`。見出しを増やす時も列を足さずに名前を1つ足すだけ
- `info_sorted_at`（最後に振り分けた・直した時）
- まだ振り分けていない人は空。今の `info` の文はそのまま残す（＝振り分け前の文）
- 区分（家庭訪問する／しない）は持たない

## 保存のしかた（2026-10-27 ヒデさん指示）

| 項目 | 決まり |
|---|---|
| いつ保存するか | **メンバーページと訪問ログを書く画面は、右上の「保存」を押した時だけ保存する**（前は 打った端から自動で保存していた）。入力は いったん「保存待ち」にためる。写真も 情報の段も 住所が分からない時の段も 同じく「保存」まで待つ（情報の段の ✓ は「直し終える」で、保存は右上でまとめて） |
| 保存せずに戻る時 | 「保存していない入力があります／このまま戻ると、入力した内容は消えます」の確かめの画面（キャンセル／消して戻る）。戻るボタン・左端から右へのスワイプ・ブラウザの戻る・下のタブ のどれでも出る。ページを閉じる・読み込み直す時は ブラウザの決まりの確かめ（見た目は変えられない） |
| 控え（バックアップ） | 保存するまでの入力は この端末の中（localStorage）にも控えを置く。アプリが落ちた・閉じた後に もう一度開くと「保存していない入力が残っています。戻しますか？」（捨てる／戻す）。保存したら控えは消す |
| 自動で入る物 | 読み仮名の自動の推測（（仮）付き）は これまでどおり 開いた時に自動で保存する（入力ではないので 戻る時の確かめを出さない・仮置き） |
| 地図のシート | 地図のメンバーのシートの ブックマーク などは これまでどおり その場で保存（保存のボタンが無いため） |

## メンバーページの白い段（2026-10-27 ヒデさん指示）

- 上の「情報」の見出しと 右の鉛筆は無くし、白い段（外見・印象的な出来事・情報・写真）だけが並ぶ
- **白い段ごとに「編集／完了」**のボタンを見出しの右に置く。外見と印象的な出来事は 鍵がかかっている間は出さず、Face ID で開けると出る
- メンバーページでは 段から段へ つまんで動かすのは無し（おまかせ入力の確認の画面だけで動かせる）
- 白い段の見出しは 全部同じ大きさ（16px・太さ600・灰色。基本情報・ステータス・外見・印象的な出来事・情報・写真）
- 直した その場で「保存待ち」にためる（打っている途中でも）。元の中身に戻したら 保存待ちから外す。戻る時の確かめは、押した・打った その瞬間の入力で決める（打っている途中の欄は 先に閉じてから見る）
