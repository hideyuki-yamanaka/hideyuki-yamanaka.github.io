# メンバー情報（メンバータブ）の仕様

> 決めた日: 2026-10-26（ヒデさんと質問しながら固めた）。作業場所: houmon-app の `update/member-book` ブランチ。
> 狙い: 家庭訪問アプリを軸にしたまま、「訪問しない人の情報も忘れないように残せる」メンバー情報のアプリにもする。
> 作りは「名簿は1つ・区分で分ける」「情報は決まった見出しに振り分ける」のシンプルな形にして、あとから広げやすくする。

## 決まったこと

| 項目 | 決まり |
|---|---|
| 入れる人 | 名簿は1つのまま（今の男子部のメンバーと同じ）。1人ずつ **区分「名簿」か「訪問ログ」** のどちらかを持つ（呼び名は 2026-10-26 ヒデさん「左側に名簿、右側に訪問ログという名称」） |
| 区分の効き方 | 訪問ログの人＝地図のピン・ホームの一覧・ダッシュボードの数に出る。名簿の人＝メンバータブだけに出る（カレンダーは区分で隠さない） |
| 区分の切り替え | 1人のページの名前の横に **切り替えスイッチ（左＝名簿・右＝訪問ログ）**。**名簿が既定**（新しく登録した人は名簿から。今いる人は訪問ログから始める＝仮置き。全員を名簿にすると地図のピンが消えるため）（2026-10-26 ヒデさん決定） |
| 区分の絞り込み | メンバータブで区分で絞り込める（形は見本から選ぶ・未定） |
| 名簿の並べ方 | **すっきり一覧**（1行に1人：かな・名前・ヤング・所属・›）（2026-10-26 ヒデさん決定・見本の案2） |
| AI の案の確かめ方 | **1件ずつ確かめる＋編集で動かす**：4つの見出しはいつも固定で並べ、中身を1件ずつ ✓ で入れる／外す。右上の「編集」を押すと、各行の右のつまみ（十字）を持って 別の見出しへ動かせる・並びも変えられる（例：特徴 → 印象的な出来事）。空の見出しは編集中は点線の受け皿になる（2026-10-26 ヒデさん「セクションが固定で、その中身を編集ボタンでドラッグアンドドロップ」） |
| 情報の見出し | **家族構成・特徴・印象的な出来事・その他** の4つ |
| 見出しの育ち方 | 家族構成・特徴・その他は「今の姿」を AI がまとめ直す（食い違えば新しい方）。**印象的な出来事だけは消さずに日付つきで積む** |
| 話して入れる入口 | **ホームの＋（おまかせ入力）だけ**。家庭訪問の流れの中で、AI が「訪問の記録」と「情報の更新」に振り分ける |
| AI の更新の仕方 | **案を見せてから保存**（見出しごとに足す分を見せる・話した原文も残す・やり直せる） |
| 今の「情報」の文 | AI で4つの見出しへ**自動で振り分ける**。元の文は各人のページに「振り分け前の文」として残す。振り分けの前に何人か分を見本で見せる |
| 下のタブ | **ホーム・カレンダー・メンバー・ダッシュボード**（設定の場所にメンバーを入れ、ダッシュボードと入れ替え） |
| 設定 | 地図の右上（前の「地図の見た目の切り替え」ボタンの場所）に置く。地図の見た目の切り替えは、いったん無くす |
| メンバータブの名簿 | ホームの一覧と同じ絞り込み（見出しで男子部／ヤング・本部・部・地区・並び替え）。区分の絞り込みを足す |
| 1人のページの見せ方 | 未定（見本の3案） |
| 版の番号 | 大きいアップデートなので、main に乗せる時に v2.0.0 にする（仮置き） |

## データの持ち方（案・作る時に SQL を渡す）

- メンバーに `kind`（`roster` 名簿 / `visit` 訪問ログ）を1つ足す。新しく登録する人の既定は `roster`。今いる人は全員 `visit` から始める（仮置き）
- メンバーに情報の4つの見出しを足す: `info_family` / `info_trait` / `info_other`（文）と、`info_events`（日付つきの出来事の並び）
- 振り分け前の文は今の `info` をそのまま残す（消さない）
- 見出しや区分は、あとから増やせるように「決まった名前の一覧」で持つ（今は4つと2つ）

## 見本

ローカル: `http://localhost:3098/mock/member-book`。2026-10-26 ヒデさん「一覧で見ると見にくい。遷移してその案を確かめる形に」で、
**一覧のページ（決めることごとに案を並べる・決定／未定の印）→ 押すと その案がスマホいっぱいの本物の大きさで開く**（`/mock/member-book/view?s=段&p=案`。上の黒い帯で一覧に戻る・同じ段の別の案へ移る）形にした。

| 段 | 決めること | 状態 |
|---|---|---|
| 1 | 名簿の並べ方 | 決定：すっきり一覧 |
| 2 | 1人のページの見せ方 | 未定：見出しごとのカード／1枚にまとめて切り替え／開け閉め＋時の流れ |
| 3 | AIの案の確かめ方 | 決定：1件ずつ確かめる＋編集で動かす（触って動かせる） |
| 4 | 名簿／訪問ログの切り替え方 | 決定：切り替えスイッチ（左＝名簿・右＝訪問ログ） |
| 5 | 名簿／訪問ログの絞り込み方 | 未定：3択の切り替え／条件の帯に「区分」／チップで選ぶ |

見本の仮置き（本番では AI とデータベースが受け持つ）:
- 区分はまだデータに無いので、訪問の記録が1件も無い人を「名簿」として見せている
- 4つの見出しへの振り分けは、言葉の手がかりで仮に分けている
- 話した原文は、その人の情報の2行を「話した」形にしたもの（作り話は足していない）。訪問日は 10/26 として見せている
- 個人の情報はファイルに書き込まず、開いた時にデータから読む

## 本物の画面に入れた物（update/member-book）

- 下のタブを4つ（ホーム・カレンダー・メンバー・ダッシュボード）にした
- 地図の右上を設定ボタンにした（地図の見た目の切り替えは外した）
- メンバータブ（/members）: すっきり一覧（決定）・男子部／ヤング・本部・部・地区。区分の絞り込みはまだ
