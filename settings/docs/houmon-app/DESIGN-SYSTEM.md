### 見た目をそろえる決まり（レギュレーション）

目標は「数字がそろっている」ことではなく **目で見て アイコンと文字の強さ・大きさがそろって見える** こと。

| # | 決まり | 中身 | 理由 |
|---|---|---|---|
| 1 | 線の太さは 1 つ | アイコンの線は **アプリ全体で標準（400）1 種類**。画面や場所で細くしたり太くしたりしない | 線の太さがバラバラだと、それ自体が不揃いに見える（細め 300 と切り替える案は試してやめた） |
| 2 | 差は文字の太さで縮める | アイコンの横の **普通の文字は 中太（500）** にする。太字（700）の横はそのまま | 同じ大きさの文字より アイコンの線の方が太いので、普通の文字だとアイコンが勝って見える |
| 3 | 色は横の文字と同じ | 文字の横のアイコンは **その文字と同じ色**（色を指定せず 文字の色を受け継ぐ）。文字の無いアイコン（丸ボタン・見出しの右のボタン）は 濃いグレー `--color-text-2` | アイコンだけ濃いと 文字より強く見える |
| 4 | 大きさは文字の大きさで決める | 横の文字 10〜12px → アイコン **16px** / 16px → **20px** / 20px → **24px**。丸ボタンの中は **丸の半分**（丸 40 → 20 / 48 → 24） | マテリアルは枠の中に余白があり 形は枠の 7〜8 割。同じ数字だとアイコンが小さく見える |
| 5 | 形ごとの錯視を補正 | 枠の大きさはそのまま、中の形だけ拡大（`gen-icons.mjs` が自動）。**形の長い方が 15 未満（24 の枠の中）なら 17 まで拡大（最大 1.25 倍）**：☆ 1.25 / 👤 送信 戻す 更新 1.21 / 矢印 1.24 / 地図の重なり 1.18。**📍 は細くとがっているので手で 1.125 倍** | ☆ は 13.6×13 しか使っておらず、18×18 の 🕒 ✥ と並ぶと 3 割小さく見えた |
| 6 | 補正しない記号 | › ‹ ⌄ ⌃ × ＋ ✓ と 文字装飾（B / I / H1 / H2 / リスト）、読み込み中の回転 | もともと小さく見せる記号。大きくすると主張が強すぎる |
| 7 | 形の大きさの記録 | アイコンを足したら ブラウザで形の大きさを測って `scripts/icon-extent.json` に追記する | 5 の自動補正がこの表を使う |

| その他 | 中身 |
|---|---|
| 形 | **線が基本**。**塗りは「ON の時」だけ**（下のタブの選んでいるタブ・ブックマーク中の★） |
| 大きい絵 | 読み込み中 28px / カレンダーの空の画面 48px（白い丸の中） |
| 地図のピンの中の記号 | ★・＋ も Material の形（HTML の文字列で作るので `MapView.tsx` の先頭に形を写してある） |
| 文字の記号 | `×` `→` `＋` をアイコン代わりにしない（アイコン部品に置き換えた） |
| 例外 | 「戻る」の ‹ は 24px（‹ は細い線だけの形なので 20 だと小さい）。クイック入力の入口（メンバーを登録・訪問ログを記録）のアイコンは青（押せる入口の目印） |

## 運用ルール

1. 新しい色・影を足す時は **まず globals.css に役割の名前で足す**。画面に色コードを直接書かない
2. 数値は上の「数値のルール」の目盛りから選ぶ
3. ⚠️ globals.css を書き換えたら、ローカルの開発サーバーが気づかないことがある
   → `rm -rf .next` して起動し直し、配信中の CSS に反映されたか curl で見てから画面を確認する（[FIXLOG](../general/FIXLOG.md) 2026-09-27）
4. 印刷ページ（`components/print/`・`app/members/print/`）は紙の寸法（pt・mm）で組んでいるので、この目盛りの対象外

## 消す操作（2026-10-05 ヒデさん指示「簡単に削除できない UI に」）

- 写真は一覧に × を出さない。拡大した時だけ写真の下に「この写真を削除」（見た目は「このメンバーを削除」と同じ＝白いカード・横いっぱい・赤い太字 16px・ゴミ箱。写真には重ねない）→ 確認（「この写真を削除しますか？／元に戻すことはできません。」キャンセル／削除する）の 2 段階で消す（`PhotoField`。メンバー詳細の情報・訪問ログの記録画面の両方）
- 確認の形はメンバー削除の確認と同じ（赤い丸のアイコン・題名 16px 太字・説明 12px・下に 2 つのボタン）

### 下のタブの周り（2026-10-05 ヒデさん「タブの周りで地図やカードが透けて使いづらい → Slack のように」）

- 下から出るシートは、箱を画面の一番下まで伸ばし、中身が下のタブの下をくぐる（Slack と同じ）。見えている高さ（半分・小さく開いた時）は 下のタブ＋ホームバーの分を引いて今まで通り。一番下までスクロールした時は 最後の中身がタブの上に来るよう 下に余白（`--sheet-bottom-inset`＋16px）
- 下のタブの後ろに「なめらかに消えていく帯」（`.tab-bar-fade`）：**下のタブの上の線から**画面の下まで、後ろの中身が 画面の地の色（#F2F2F7）へ ゆるやかな曲線で消える（一番下で 75%）。ぼかし・切り抜きは使わない（「ぼかしはやりすぎ」「急で不自然」で 2026-10-05 にやめた）。全画面共通（仮置きの値）
- 切り替えスイッチの外側の地は iOS と同じ薄いグレー（rgba(118,118,128,0.14)）、選ばれていない側の文字は濃い灰色（`--color-text-2`）。ガラスの白い地では見えにくかったため

### メンバー一覧の余白とページ切り替え（2026-10-05 ヒデさん決定）

- 「すべて／ヤング」と本部・部・地区の段：上 12px・段どうし 8px・下 8px（「少し広め」。前は 8／4／0）
- 絞り込みのまとまり（スイッチ〜「訪問状況」の帯）と メンバーのカードの間は 24px（中の余白 8px の 3 倍。近接の法則で 別のまとまりに見せる。2026-10-05 ヒデさん「除外ブロックとカードがセットに見える」。前は 4px）
- フィルター・並び替えは シートの上に重ねず、**シートの中のページに切り替える**（`SheetPages`）：右からページが入り、一覧は少し左へ下がって消える。見出しの左に「←」。**シートの高さは変えない**（中身だけ入れ替える。一番小さく畳んでいる時だけ半分まで上げる）。新しいページの見出しは 一覧の見出しと同じ高さ 28px・同じ位置（「フィルターを押すとレイアウトシフト」で 2026-10-05 に直した）。速さとカーブはボトムシートと同じ（380ms・cubic-bezier(0.32,0.72,0,1)）。同じような「シートの上にシート」を新しく作る時も この形にする
