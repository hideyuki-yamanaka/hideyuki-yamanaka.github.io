# houmon-app 共有リンク（URL だけで訪問ログを見せる）

> 2026-09-27 作成（ブランチ `update/share-link`）。招待（チームに入れる）とは別物。

| | 招待 | 共有リンク |
|---|---|---|
| 相手の準備 | メールでログインしてチームに入る | リンクを開くだけ（ログインなし） |
| 閲覧できる範囲 | アプリ全部 | 共有範囲だけ（期間／地区／メンバー／訪問ログ） |
| できること | 閲覧のみ or 編集可 | 閲覧のみ |
| 閲覧期間 | 外すまでずっと | 発行する時に選ぶ（1日／7日／30日／無期限）。いつでも取り消せる |

## 作り

- 入口: 設定 →「共有・招待」（`/settings/sharing`）で「招待する」（`/settings/sharing/invite`）か「リンクで共有」（`/settings/sharing/link`）を選ぶ（2026-09-27 ヒデさん指示で 2 つを 1 つの入口にまとめた）
- 作る・一覧・取り消す: 「リンクで共有」の画面（持ち主だけに見える）
- 見る人のページ: `/s/<32 文字のランダム>`（ログイン不要・下のタブなし・検索に出さない noindex）
- 画面: 「共有設定」1 ブロックの中に「共有範囲」（プルダウン: 期間／地区／メンバー／訪問ログ）と「閲覧期間」。「住所を伏せる」は ヒデさん指示で無し（表の hide_contact 列は残っているが使わない）
- 言葉は 招待の画面とそろえる: リンクを発行／発行済みのリンク／閲覧できる・期限切れ・取り消し済み／閲覧数／共有／取り消す
- 見る人に渡すのは **名前・読み仮名・年齢・所属・住所・訪問ログ（日付・結果・対応者・メモ・書いた人）** だけ。電話・家族・情報欄・備考・写真は渡さない
- データベース: 表 `share_links`（`houmon-app/sql/2026-09-27-share-links.sql`）。RLS で持ち主本人しか読めない。見る人のページはサーバーが service role で読み、範囲の中身だけ返す
- 窓口: `/api/share`（一覧・作成）`/api/share/revoke`（取り消し）`/api/share/view/<token>`（見る人用）
- ローカル（お試しモード）は `.dev-data/share-links.json` と本番データの控えで同じ動き（gitignore 済み）
