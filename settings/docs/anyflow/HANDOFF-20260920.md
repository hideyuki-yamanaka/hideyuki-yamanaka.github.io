## 2. 動かし方・確認の仕方
- **本体の配信は常駐**：`http://localhost:8778/`（LaunchAgent で常駐＝`preview_start` は使わない。落ちてたら [project_anyflow_local_launchagent] 参照。ポート 8778 = v5、ルートが `anyflow/v5/`）。スマホ実機は同じWi‑Fiで `http://<PCのLAN-IP>:8778/`（実測 172.16.15.153）。
- **ライブ同期の中継サーバ**：`node anyflow/v5/tools/live-sync.mjs`（port 8779）。`.claude/launch.json` の `anyflow-live-sync` が自動起動。PCで調整パネルの「📱スマホモード」→QR→スマホで読むと、PCのつまみ操作がスマホにリアルタイム反映。
- **描画を伴う検証は Playwright（swiftshader）**で。Browserパネルは非表示だと rAF が止まり空白になるので、`design-gallery/node_modules/playwright` を使う。定番パターン：
  ```js
  import { chromium } from '/Users/hideyuki/Developer/Claude Code/design-gallery/node_modules/playwright/index.mjs';
  const b = await chromium.launch({ args:['--use-gl=swiftshader','--no-sandbox'] });
  const p = await b.newPage({ viewport:{width:1440,height:900} });
  await p.goto('http://localhost:8778/', { waitUntil:'domcontentloaded' }); // ?live=phone は SSE 常時接続で networkidle にならない→domcontentloaded
  await p.waitForTimeout(2500);
  // 値の実測は検証用の窓から: window.__anim._params()=現在のparams / window.__anim.mb()=SP専用の上書き一覧
  ```
- **PC/SP独立の実測**：`html.phone-mode` を付けてつまみを動かすと `params.mb[パス]` に入り base は不変。実機反映は狭い幅(≤600px=isMobile)で `applyMbToParams` が流し込む。往復は「PC(localhost:8778)で save() → phone(?live=phone・幅390)で受信」の2コンテキストで確認（中継8779が要る）。

## 3. 今セッションで入れた仕組み（要点）
すべて **PC/SP独立の絶対ルール**に沿う。詳細は §1 の資料へ。
- **PC/SP独立の汎用土台 `mbKey`**：`slider(..., { mbKey:'ドットのパス' })`。スマホモード中はその項目だけ `params.mb[パス]` に書き、PCの base は触らない。起動時/ライブ反映時に `applyMbToParams()`（isMobile の時だけ）が本体へ流し込む。**約237つまみに付与済み**（KV文字・KVグラフィック=`conv.*`全部・実績・開発者体験・ビジョン・お問い合わせ・メニュー等）。青印=`row.mb-override`、スマホは `save()` 無効（閲覧専用）。
- **調整パネルの自動整列**：各小見出しに `data-grp`(自動判定＋`opts.grp`上書き)、`buildPanel()` 末尾で `applyPanelGroupOrder()` が全タブを同じ順に並べ替え。
- **スマホモードのハイライト**：つまみは input(ドラッグ)時、文字行は入力/選択時に即ブルー印（左に青バー＋薄い青背景＋●）。
- **リセット(↺)＝このセッションを開いた時の値に戻す**：起動直後の params を `SESSION_START` に控え、`sessionOf(get)`(params差し替え)で復元。スマホモード中は必ずSP上書きだけ解除しPC値は不変。
- **ライブ同期の順序修正**：`liveApplyNoReload` で「案適用(applyKvVariant/varApply)→SP流し込み(applyMbToParams)」の順（リロード時と同順）。以前は逆で、線幅を変えると惑星/カゴが勝手に変わっていた。
- **KV距離つまみ**：新サブ「余白（ヘッダー・グラフィックとの距離）」に ①`kv.hlOff`(見出しの基準top 208/434 に足すオフセット=--kv-hl-off) ②`kv.gfxY`(右グラフィックの縦オフセット)。
- **SPロゴ帯の見切れ根治**：`KV_MB_H` を 667→704（`.stage-wrap` が overflow:visible なので、器がロゴ帯途中で切れて次セクションが下半分を覆っていた）。
