## 本体から維持するもの

`reference.html`、`demo.html`の全体はV4原本のスナップショット。本文・実績数値は静的な原文から抽出する。カウンター再生中の見かけの数字をデータとして読まない。

- 書体、文字ウェイト、SaaS/AIの色、SVGの図形・矢印、Vision、開発者体験、元の背景グラデーションを継承。
- ピクトは原本のS18（3.6秒）とA21（4.4秒）。時間駆動でループ。古い保存設定の`running=false`でモックのピクトまで停止させない。
- トリミング長はSVG座標を保ち、線幅のみ倍率で補正して約1.5 CSS px。水色の経路を途切れた複数線へ描き直さない。
- ユーザー指定の例外として、S18の図の下の横線（x=36→184、y=166）だけ非表示。
- 数字はV4の`buildSlots`と`renderSlots`を再利用。3周、開始0.3秒、継続1.4秒、桁差0.12秒、イージング指数5。画面高さ85%への入場で自動再生。
- 数値を並べ替える構成は`data-slot-index`で原本の指標へ対応させる。20,000+を先頭にしても100+のリールを誤って使わない。
- スロットは完成値をaria-labelに持ち、0〜9の繰り返しを読み上げない。
- 公開V4のピクト・スロットとの前回照合は2026/09/14。公開HTML SHA-256: `31ff1944f516a571f4410090c51d711edc1440d78996e4fcfa097af8c9e99e21`。今回その本体を更新・置換していない。
