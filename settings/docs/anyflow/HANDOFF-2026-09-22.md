1. **ビジョンのメッシュ機能名を矢印位置まで上げる**（commit e3b1ccfe）
   - `applyVfFade()`（~L12517）の SP 持ち上げ `_mbLabGY` 既定を **-38→-120**。SDK ラベル上端が画面 260→215px（メッセージ直下＝矢印先端）。
   - PC は持ち上げ処理 `_pcLabLift` を**撤去**（元通り）。`_invSp` は SP のみ。
2. **メッシュを少し小さく＋Point を上に詰める**（commit 84f92dd2）
   - SP CSS（~L3095）`.vf-wrap transform: scale(0.555→0.50)`。ラベルは小さくならないよう `.vf-lab b 21→23 / span 11→12`。
   - `.val-p1 top 508→470 / .val-p2 593→555`。**セクション高は JS `fixH('vision','#valP1,#valP2',16)`（~L16353）が Point 下端+16 で自動計算**→Point 上げれば下のセクションも自動で詰まる。
3. **メッシュを中央へ＋機能名を左右に開く**（commit 6a39967e）
   - 左寄りの真因＝ scale 0.50 縮小（原点左上）で球中心が 174px に左ズレ→`.vf-wrap left 28→49`（球中心 195px＝画面中央）。
   - `applyVfFade()` に per-label 横オフセット `_mbLabGX=[-76,-32,0,32,76]`（index=[コネクタ,認証,SDK,WF,実行]。SP のみ・`_mb?[...]:null`）。コネクタ/認証=左、WF/実行=右、SDK 中央。球の各高さの幅を実測し重ならない量に。
4. **実績セクションの罫線ブロックの上下余白を見た目60pxに揃える＋本文→ピクトを詰める**（commit f19fa1fb）
   - **真因＝ピクトグラム SVG の透明下余白**（SaaS≈55/AI≈63px）で箱がカード下端より下に伸び、データ上20pxでも見た目75pxに膨張していた。
   - SP `rfx-24`（アクティブ変数）: `.r2v-graphic margin-bottom -15`（AI は `:has(.r2v-tag-ai)` で -23）、`res2-hr-top`/`res2-vline` 下 margin 4→46、`r2v-fig margin-top -12→-28`。
   - 実測: SaaS 上61/下60、AI 上61/下60、本文→ピクト 48/46px。

## 7. ハマりどころ（次の人へ）
- **メッシュのラベル位置は `applyVfFade()` が `el.style.top/left` に書く。`vfDraw()` は canvas 描画だけでラベルに触らない**。位置検証で vfDraw を呼んでも動かない（今回これで誤判定した）。
- SP の `.vf-wrap` は `.pin-stage` ではなく **自身の `transform: scale()`** で縮小。scale を変えると球が左上にズレる＆ラベルも縮む→ left と font-size で補正。
- 実績のピクトは**箱(224px)に透明余白**があり、線との見た目余白が箱の余白と一致しない。線の位置合わせは透明余白を margin で相殺する。
- `:has()` は実機モバイル Chrome/Safari で有効（今回 AI ピクトの出し分けに使用）。
