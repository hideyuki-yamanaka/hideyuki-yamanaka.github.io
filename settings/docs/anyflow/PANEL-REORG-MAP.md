## 凡例（操作）
- **残** … そのまま／**名** … 改名（現名 → 新名）／**移** … カテゴリ or オブジェクトを移す
- **分** … 混在ブロックを分割／**削** … 削除／**新** … 新しい見出し（オブジェクト）を作る

### KV の判断メモ（仮置き）
- **旧アニメ案のブロック**（軌道・ドット・エフェクト・各「この案の調整」）は、いまの KV（メッシュ案固定）では画面に出ない残置コード。**その他** に畳んで置く案。**「いっそ削除」でもOK**（要相談）。
- 「出るタイミング」が2か所（グラフィック直下と、コピー>タイミング）にある＝**同じ値の重複**。1つに統合。
- 文字サイズ（メイン/最終行/サブ）は `🔤 文字` の「サイズ」欄とも重複しうる。**統合はリスクありなので後回し**（今回は別項目のまま「フォント」に集約）。
