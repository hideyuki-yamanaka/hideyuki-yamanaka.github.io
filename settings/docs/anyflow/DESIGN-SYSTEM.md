## 5. 整理の記録（2026-09-19）

| 統合前 | → | 統合先 | 理由 |
|---|---|---|---|
| `#111`（ドロワー CTA 文字・送信ボタン背景） | → | `--ink-strong` / `--surface-cta` | 見分けがつかない黒。2か所だけ |
| `#fff` の生書き 11か所 | → | `--ink-on-dark`（文字・線） / `--surface-white`（面） | 役割で名前を付けた |
| `#090909` の生書き | → | `--surface-cta` | 同じ値がトークンにあった |
| `#9BE8A4` / `#434343` | → | `--code-green` / `--surface-dark-bottom` | 09-09 の統合で「寄せる」と決めた値が生で残っていた |
| 角丸 `--radius-md:14px` `--radius-lg:24px` → 後で 8/16 に上書き | → | 8 / 16 を1か所で定義 | 二重定義をやめる |
| 文字 13px（フォームのラベル・同意文） | → | 14px `--fs-body` | +1px。段数を減らす |
| 文字 15px（入力欄・送信ボタン） | → | 16px `--fs-base` | +1px |
| 文字 11px（フォームの注記2か所） | → | 12px `--fs-caption` | +1px（開発モックのコード 11px は「画面写し」なので残す） |
| 行間 1.85 / 1.9 | → | 1.8 `--lh-body` | 見分けがつかない |
| 行間 1.35 / 1.3 | → | 1.4 `--lh-tight` | SP の KV は 3 行で +5px。ロゴ帯(624px)まで余裕あり |
| 行間 1.5（注記） | → | 1.6 `--lh-normal` | 見分けがつかない |
| 余白 7px（Point ■とラベルの間） | → | 8px | 4px グリッド |
| 余白 18px（ドロワーの番号と文字・フォームの行間・SP 実績） | → | 16px | 4px グリッド。−2px |
| 余白 27px（事例カード内） | → | 28px | +1px |
| 余白 13 / 42（送信ボタン）・34（フォーム内側・セレクトの右）・22（開発リストの内側） | → | 14 / 40・32・24 | ±2px 以内 |
| 角丸 5px（SP の CTA） | → | 6px `--radius-btn` | PC と同じ |
| イージング `(.25,.1,.25,1)` 3か所 / `(.22,1,.36,1)` 1か所 | → | `--e-standard` / `--e-out` | 名前を付けた |

残した生の値（理由つき）: ロゴ帯の 30px（目視で詰めた値・2026-09-18）、1〜3px のヘアライン調整、開発モックの内側（画面写し）、字間（5か所・意図的）、負の座標オフセット。

## 7. これから値を足す時

1. `/*DS-TOKENS-START*/` の `:root{}` に**名前を付けて**足す（大きさで決まる物=`カテゴリ-値`、意味で決まる物=`カテゴリ-役割`）
2. CSS では名前だけ使う。px や HEX を直接書きたくなったら「名前が足りない」サイン
3. 案の比較(mock・調整パネル)の値は本番のトークンに混ぜない
