# anyflow V5.0 調整パネルの構成ルール（統一・大改修 2026-09-20 改訂）

> **この文書が調整パネルの「正」。新しく項目を足す時・作り直す時も、必ずここを参照する。**
> 独自カテゴリ・独自命名を勝手に作らない（ヒデさん強い指定 2026-09-20）。
> 旧版（バリエ→基本→フォント→カラー→テクスチャ→アニメ の6グループ自動整列）は、
> 下の **5カテゴリ＋オブジェクト束ね** に置き換える。関連: [[ANYFLOW-PC-SP-INDEPENDENCE.md は同フォルダ]]（PC/SP独立の絶対ルールは継続）。

---

## 0. 何を直すのか（背景）
今のパネルの課題：
1. タブが切り替わると「基本」に入っている中身がタブごとにバラバラ。
2. 項目が **オブジェクト（モノ）ごと** にまとまっていない（メッシュの項目が散らばる等）。
3. **名前がゆれている**（メッシュ／カゴ、図／グラフィック、位置／X／左右…）。
4. 1つのブロックに **種類の違う項目が混在**（例: 左側コピー＝文字＋位置＋出現タイミング）。

直し方の方針＝**「①カテゴリで大きく分ける → ②その中をモノ（オブジェクト）で束ねる → ③名前を統一」**。

---

## 1. 第1階層：カテゴリ（全タブ共通・この順で固定）
タブは横1列＋横スクロール。どのタブを開いても、中は必ずこの順・この名前で並ぶ。

| 順 | カテゴリ | 入るもの（判定の目安） |
|---|---|---|
| ★ | **バリエーション（案）** | 案を選ぶUI（案があるタブだけ・5カテゴリの上に固定）※§6で要確認 |
| 1 | **基本** | 位置・余白・間隔・大きさ・幅・高さ（レイアウトの寸法） |
| 2 | **フォント** | 太さ・行間・字間・文字サイズ（文字スタイル） |
| 3 | **エフェクト＆テクスチャ** | 見た目の演出（光・影・ぼかしの質感）／質感（ガラス・ディザ・網目の線）／**配色（色）** ※§6で要確認 |
| 4 | **アニメーション** | 出る・消えるタイミング／ディレイ／順番／速さ／登場・退場・切替の演出 |
| 5 | **その他** | 上のどれにも収まらない暫定の置き場（後から正しいカテゴリへ移す） |

---

## 2. 第2階層：オブジェクト（モノ）で束ねる
- **同じモノに効く項目は、そのモノの見出し（オブジェクト）の下にまとめる。**
- モノが違えば見出しを分ける（例: **惑星 ≠ メッシュ**。惑星の大きさをメッシュに混ぜない）。
- **1つのモノが複数カテゴリにまたがってよい。** 同じ「メッシュ」でも、
  - 大きさ・傾き → **基本 › メッシュ**
  - 線の濃さ・太さ → **エフェクト＆テクスチャ › メッシュ**
  - 回る速さ・パケット → **アニメーション › メッシュ**
  のように、**各カテゴリの中に同じ名前の見出しを置く**（名前は必ず同一にする）。
- **似た項目は隣に置く**（例: ノードの数・ノードの大きさ）。

---

## 3. 命名の統一（表記ゆれ禁止・パネル全体で共通）
- **総称は「グラフィック」**。その中の要素は用途語で呼ぶ：**メッシュ（網）／惑星／ロゴ／機能名** など。
- **「カゴ」は使わない → 「メッシュ」に統一。**
- **「図」は使わない → 「グラフィック」に統一**（要素はメッシュ・惑星…）。
- **位置の軸語は「左右／上下／奥行き」に統一**（`X`/`Y`/`Z`・「位置 横」等は使わない）※§6で要確認。
- **冗長排除**：オブジェクト見出しにモノ名があれば、子項目からモノ名を省く。
  - 例）見出し **「メッシュ」** → 子は「傾き（前後）」「向き」「線の太さ」（×「メッシュの傾き」）。
- 向き・単位の言い方も揃える（「＋で右／下」「◯px」「◯秒」「×◯.◯」）。

---

## 4. カテゴリ振り分けの判定（迷ったらこの表）
| 項目の性質 | 行き先 |
|---|---|
| 位置・余白・間隔・大きさ・幅・高さ | **基本** |
| 太さ・行間・字間・**文字サイズ** | **フォント** |
| 色・グラデの配色 | **エフェクト＆テクスチャ**（配色）※§6 |
| ガラス・ディザ・網目の線（濃さ/太さ）・光・影・立体感・見た目のぼかし | **エフェクト＆テクスチャ** |
| 出る/消えるタイミング・ディレイ・順番・速さ・登場/退場/切替の演出・回転の速さ・出現ブラー | **アニメーション** |
| どれにも当てはまらない／判断保留 | **その他** |

### 混在ブロックは分割する
1ブロックに種類の違う項目が混ざっていたら、上の表でカテゴリごとに割り直す。
- 例）KV「左側コピー」＝**コピー文字（フォント）＋位置（基本）＋順番・打つ速さ（アニメ）**
  → 基本 › コピー（位置）／フォント › コピー（文字）／アニメ › コピー（順番・タイミング）。
- 案（バリエーション）に紐づく細かい調整は、**その案の近く**（バリエーション枠の直下、または該当カテゴリ内のオブジェクト）に置く。

## 5. 実装メモ（コードの住み家）
- タブ＝`category()`（`.cat` / `.cat-body`）。タブバー＝`.pan-tabs`（横スクロール化済み 2026-09-20）。
- 小見出し＝`sub(target, ラベル, deep, opts)`。カテゴリ印は `opts.grp`（無い時は `grpFromLabel()` が言葉から自動判定）。
- 並べ替え＝`applyPanelGroupOrder()`（`buildPanel()` 末尾）。**この大改修で GRP_ORDER と grpFromLabel を新5カテゴリに更新する。**
  - 新 `GRP_ORDER`（予定）: `variation:0, basic:1, font:2, fxtex:3, anim:4, other:5`
  - `grpFromLabel` のキーワードも新カテゴリに合わせて更新（`色/配色 → fxtex`、`ディザ/ガラス/網/光/影/質感 → fxtex`、`タイミング/ディレイ/順番/登場/速さ/出現 → anim` 等）。
- **PC/SP独立（`mbKey` / `params.mb` / `applyMbToParams`）は全項目で維持**（[[ANYFLOW-PC-SP-INDEPENDENCE.md は同フォルダ]]）。見出し・並びを動かしても mbKey は変えない。

## 6. 🔴 要確認（このルールで仮置きした3点・ヒデさんに確認してから確定）
1. **バリエーション（案）の置き場所** … 仮: タブ先頭の独立枠（5カテゴリの上）。
2. **配色（色）の置き場所** … 仮: 「エフェクト＆テクスチャ」の中に「配色」見出し。
3. **位置の軸語** … 仮: 「左右／上下／奥行き」。

判断が決まったら、この§6を消して本文へ確定反映する。

## 7. 進め方（この大改修の手順）
1. **対応表を先に作る**（[PANEL-REORG-MAP.md](PANEL-REORG-MAP.md)）：全タブ・全項目を「現状 → カテゴリ → オブジェクト → 新名称 → 操作(残す/改名/移動/削除/分割)」で一覧化。
2. 対応表をヒデさんが確認・修正 → 確定。
3. 確定した対応表 **だけ** を根拠にコードを直す（推測でカテゴリを決めない）。
4. 直したら Playwright で「タブごとの並び順・見出し名・項目の所属」を実測してから完了と言う。
