# anyflow V5.0 調整パネルの並び順・グループ（統一ルール）

> 2026-09-20 制定。ヒデさん依頼「タブが切り替わっても同じ順番・同じ名前で。理解コストを下げたい」。
> 方式は**自動整列**（各見出しにグループ印を付け、組み終わりに自動で並べ替え）。関連: [[ANYFLOW-PC-SP-INDEPENDENCE.md は同フォルダ]]。

## グループと並び順（全タブ共通・固定）
1. **バリエーション（案）** — 案の選択と、その案に紐づく調整（一番上位）
2. **基本** — 長さ・ぼけ・位置・大きさ・間隔などレイアウト寸法
3. **フォント（🔤 文字）** — 太さ・行間(lh)・字間(ls)
4. **カラー（配色）** — 色・グラデ配色
5. **テクスチャ（質感）** — ガラス・ディザ・立体感・網目など
6. **アニメーション** — 出るタイミング・順番・演出・揺らぎ

## 実装（コードの住み家）
- `sub(target, label, deep, opts)` が小見出しを作る時、`opts.grp` があればそれを、無ければ **見出しの言葉から自動判定**（`grpFromLabel`）してグループ印 `data-grp` を付ける。
- 判定キーワード（`grpFromLabel`）:
  - font: `🔤` / `文字（太`
  - variation: `バリエーション` / `演出の案` / `案…：`
  - color: `配色` / `カラー`
  - texture: `ディザ` / `ガラス` / `立体感` / `網目` / `質感` / `テクスチャ`
  - anim: `タイミング` / `アニメ` / `演出` / `順番` / `登場` / `揺らぎ` / `つなぎ` / `一旦止まる` / `出入り` / `入場`
  - それ以外 → basic
- 自動判定が合わない所は **明示で上書き**：`sub(cat, 'ラベル', deep, { grp: 'basic' })`。現在の上書き:
  - 開発者体験「モックのスタイル（立体感）」→ **variation**（スタイルの選択＝案切替）
  - 開発者体験「この案の調整（…）」(sp.title) → **variation**
  - お問い合わせ「フォーム（横幅・磨りガラス…）」→ **basic**（横幅などフォームの基本）
- 全タブを組み終えた後に **`applyPanelGroupOrder()`**（`buildPanel()` 末尾）で、各カテゴリ(`.cat-body`)直下の小見出し(`.grp`)を上の順に並べ替える。**入れ子の小見出しは親ごと動く**ので触らない。タブ先頭の説明文(`.cat-note`)は最上部に残る。

## 新しく見出しを足す時
- 上のどれかのグループに属させる（自動判定が効くよう命名する／効かない時は `opts.grp` を付ける）。
- **同じ概念は同じ名前**にする（勝手に別名を付けない）。共通名の例:
  - 「基本（長さ・ぼけ具合）」/「🔤 文字（太さ・行間・字間）」/「バリエーション（案）」
- 位置移動は基本に、出るタイミングはアニメーションにまとめる。

## 現在の各タブの並び（2026-09-20 実測）
- 🌊 全体: 基本(慣性/くり返し/セクション見出し)
- 🖼 KV: バリエーション → 基本(グラフィック/左側コピー) → フォント
- 📖 ビジョン: 基本(基本/①/②/⑥/⑦) → フォント → カラー(配色) → テクスチャ(図) → アニメ(表示タイミング)
- 📈 実績: バリエーション(演出の案＋各案の調整) → 基本(基本/ピクト) → フォント → アニメ(入場ぼかし/順番/数字演出/つなぎ)
- 🖥 開発者体験: バリエーション(スタイル選択/この案の調整) → 基本(全部の案/間隔/長さ/スロット箱) → フォント → カラー(配色) → アニメ(一旦止まる/出入り/切替)
- 🗂 導入事例: 基本(基本/見出し) → フォント → アニメ(カード登場)
- 💠 コンバージョン: 基本(フォーム) → フォント → テクスチャ(ディザと流れ)
- 🍔 ハンバーガー: 基本(余白・間隔・大きさ) → フォント

## 🟡 追って（仮置き）
- 「🎨 グラフィック」(KV) は中に基本(位置)＋アニメ(軌道/粒/エフェクト)が同居。今は 1 ブロック=基本扱い。深く分けたい場合は基本/アニメに分割する。
- 混在ブロック（左側コピー＝基本＋タイミング 等）の分割も同様に追って。
