## 2026-09-15 お問い合わせ: 右上の白い「欠け」を薄い水色に／グラデのニュアンスを調整パネルへ — ✅ ローカル検証済み（未デプロイ）

- 直し方(すべて調整パネルのつまみ付き):
  1. **いちばん明るい所の色**(カラーピッカー・既定 **#7cc9e8 薄い水色**) … 明るい端の色そのものを指定できるように
  2. **白の残し具合**(既定 **12%**) … そこに白をどれだけ混ぜるか。かすかに残す
  3. **白飛びの頭打ち**(既定 **90%**) … コントラストで淡い色が真っ白に飛ぶのを止める上限
  4. **明るい中心をずらす 横／縦**(既定 **+0.18 / +0.12**) … 明るい中心を画面の外へ逃がして、上の帯に色を通す
  5. **色の広がり（カンプの放射）**(既定 **×1.5**) … 大きいほど淡い中心が小さくなる
- 実測: 1440・390 とも pageerror 0。既定値で上の帯に薄い水色が通り、白は淡いハイライト程度に
